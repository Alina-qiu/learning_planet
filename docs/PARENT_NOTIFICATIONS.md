# 家长消息与前台提醒

2026-11-05新增迁移045、Flutter注册/离线撤销、HMS/APNs原生接收及[远程通知服务端](PARENT_REMOTE_PUSH.md)，目标设备为华为鸿蒙4.2和iPhone。后台提醒单独启用且构建默认关闭；下文介绍前台/离线提醒，远程送达仍待真实后端与手机验收。

对应 PRD 第10节：家长只接收兑换申请、同步异常和周报，不因孩子每次操作产生消息。迁移038、消息页面和前台系统提醒已经实现并完成本地回归；应用退出后的远程推送、云端部署和原生设备验收尚未完成。

## 使用入口

验证家长 PIN → 家庭管理 → 家长消息。页面显示当前家庭各孩子的兑换待办、上周报告入口和本机同步问题，可以切换全部/未读、单条标为已读、查看对应业务页面。PIN到期后页面及已打开的通知设置弹窗均收起内容；需要返回重新验证。

“启用家长提醒”会在用户操作后申请系统权限，并把本设备当前家庭切换为家长提醒模式。该模式清除原有孩子任务通知，之后只显示三类家长提醒。可从同一页面切换回孩子任务提醒。设备模式按登录账号与家庭保存在加密缓存，切换账号不继承。

通知偏好包括总开关、三类开关和安静时段。默认总开关关闭、各类别开启、21:00至07:00静默；按家庭时区解释，支持跨午夜，开始包含、结束不包含，相同起止时间表示不静默。设置属于每位家长，普通家长和管理员各自管理，采用版本校验避免覆盖另一设备的新设置。消息列表保留当前待办，不因关闭提醒或静默而隐藏。

## 三类来源

| 类别 | 来源与去重 | 打开后的行为 |
|---|---|---|
| 兑换申请 | 服务端 `redemptions` 当前为 requested 且尚未过期的记录；每个申请一个稳定键 | 打开对应孩子的兑换记录页；已读不会审批、扣款或履约 |
| 周报 | 家庭当地每周一09:00起提供上一完整周（周一至周日）；每个孩子和周末日期一个键 | 打开周报并固定到该周日，而不是打开“截至今天的近7天”；不会自动调用AI |
| 同步异常 | 本机失败过的待同步操作、任务冲突，以及 retry/blocked/needs_authorization 图片草稿 | 打开同步中心；只读状态，不重放命令，不清除答案或业务队列 |

兑换被处理或过期后退出待办；每周报告入口随周更新。首次创建的孩子在下一个家庭自然周才产生周报入口。消息中心列出当前家庭的本机异常，原生同步提醒检查当前选择的孩子，并按孩子和UTC日期限制为每天一次；该节流日期与按家庭时区计算的安静时段是两个不同口径。

## 前台系统提醒的边界

打开或恢复应用、相关状态刷新，以及前台每30秒检查时尝试读取送达消息。进入后台停止这些检查；这是前台轮询和本地系统通知。另行启用的HMS/APNs后台链路见远程通知文档，不依赖后台常驻Flutter任务；当前未配置调试包不接收远程消息。

正常联网时先核对成员权限和通知偏好。迁移039同时返回仅供本机同步异常提醒使用的策略，包括家庭、当前可见孩子ID、通知偏好、家庭时区及服务端签发/到期时间；不缓存兑换、周报正文或审批权限。策略按账号与家庭保存在现有加密数据库中，最长有效168小时。首次使用、没有有效缓存或缓存过期时，须重新联网确认后才能发家长系统提醒。

网络连接或服务可用性失败时，有效策略只允许检查本机同步异常，不重放旧兑换/周报消息，也不提交云端送达回执。家长消息页在云端列表加载或网络失败时仍显示本机同步问题，并提供联网重试及退出本设备家长提醒模式的入口。权限拒绝等非网络错误不会降级为离线授权。

离线时间根据服务端签发时间和本机请求起止时间估算，最长接受30秒请求窗口；窗口两端都须处于安静时段外，且最晚估算时间必须早于到期时间。按家庭时区处理跨午夜和夏令时，按校准后的UTC日期限制每天一次；记录最近观察时间，发现时钟回拨则清除策略。该机制不提供防篡改时钟，仍需在真机验证系统校时和重启行为。

本机保存通知偏好前先清除旧策略并暂停投递，即使保存响应丢失也不会继续使用旧偏好；切换设备模式、相关孩子删除、账号注销及已知权限拒绝同样清理，并调用原生后台提醒关闭操作。断网期间无法立即得知另一设备的偏好修改、成员移除或孩子删除，离线同步异常提醒最长由上述168小时有效期限制；联网后重新确认。远程消息另有短期限与发送前服务端复核。

同类消息合并为固定通知ID，锁屏只显示“有兑换申请待审批”等固定文案，不含孩子姓名、奖励内容、题目、答案或异常正文。点击系统通知打开应用，详情继续由家长PIN保护。Android和iOS在提交通知前再次检查当前系统权限；Android使用私有可见性并合并同类提示。

已读与送达是两套回执。客户端把成功提交给系统的事件键写入加密去重缓存后，再提交服务端送达回执；回执丢失后用原键重试，避免每轮轮询都提示。同一账号的其他设备不会重复发送已有送达回执的事件，仍可在消息中心查看未读。**送达回执表示提交到系统成功，不保证用户看见或听见**；系统设置、进程崩溃和显示后本机写入失败仍可能造成漏提示或重复提示，业务待办不受影响。

## 权限、清理与导出

- 设置和回执表启用RLS且无客户端直接表权限；收件箱、偏好修改、已读都要求当前会话的家庭PIN授权。
- 前台送达接口返回当前家庭可见孩子的稳定键、类型、时间、引用ID及受限的离线策略；必须是有效家庭成员，系统通知仍需家长启用偏好。未登录、跨家庭或已注销会话不可读取。
- 回执按家长账号与家庭隔离，键必须属于当前有效消息；批量最多200个不同键，非法键导致整批回滚。标为已读不改变业务数据。
- 切换账号、家庭、设备模式、进入后台或发生隐私清理时，迟到结果不能继续显示或写入新范围。删除标记同时过滤服务端消息和本机收到的旧事件。
- 孩子删除清理服务端回执、本机家庭级送达去重缓存及含该孩子的离线策略，避免残留子女引用；无关家庭的策略保留。移除成员级联删除其偏好和回执；账号注销受理时立即清理。设备模式不含孩子资料，按账号保留至切换/注销。
- 迁移038把当前导出家长自己的 `parent_notification_receipts` 加入孩子导出，排除其他家长的回执及user_id/family_id。ZIP增加为35个CSV；本机未同步数据不在云端导出内。
- 服务端回执90天后可清理；本机去重缓存最多1000个键，退出账号隔离保存，孩子/账号删除时清理。
