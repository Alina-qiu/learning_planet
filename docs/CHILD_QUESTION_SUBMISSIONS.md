# 孩子录入与家长确认

2026-11-05：用户确认“孩子可以校对保存，标准答案必须经家长确认才进入奖励复习”。对应 PRD 5.4 与错题录入范围，迁移058和客户端增加独立提交流程。尚未部署到真实 Supabase 或在两类指定手机上联调。

## 操作与状态

孩子模式进入错题本的拍照/相册入口，或者本机图片草稿页；可一次导入最多10张，每张独立处理、校对和保存。孩子可留空参考答案，仍须核对题目文字并明确同意上传。编辑草稿与提交队列按账号加密保存；孩子提交不要求家长 PIN。联网取得匹配的提交回执后，清除本机图片和答案副本。

错题本的“孩子提交与家长确认”显示已提交记录。孩子模式只看到本人提交；验证当前家庭 PIN 后，家长可查看家庭内该孩子已提交的记录、原图、处理图和原始 OCR，并在校对页填写或纠正标准答案，明确确认后入库。未提交的其他成员草稿仍不可读。

提交与确认本身不发奖励。确认前仅有 OCR 草稿和提交内容，没有 `wrong_questions` 或自动复习题目。确认后使用既有正式题目、服务端答案与 1/3/7/30 调度流程。孩子当时填写的参考答案独立保留，详情明确区分它与家长确认后的正式答案。

## 一致性与权限

- `begin_child_question_upload` 绑定上传 UUID 与内容指纹，复用原有私有图片桶和每日50份限制。普通家长上传仍要求 PIN，两种草稿模式不可互相转换。
- `submit_child_question` 验证两张图片、孩子归属、字段类型/大小与 OCR 确认。首次提交内容不可改写，相同请求重试返回当前状态。
- `child_question_submissions` 每页最多50条，提交时间/UUID游标，列表只构建可见行。`child_question_submission` 校验当前账号、孩子和家长模式。
- `approve_child_question` 在家庭、复习及草稿锁内检查当前会话 PIN 和实际到期时间；调用既有正式题目校验，创建题目并保存确认操作者、时间和审计。私有确认 UUID/操作者/内容指纹使同请求重放返回原题；其他确认请求或不同答案返回冲突，避免重复入库。
- 客户端在请求前后核对账号、家庭/孩子、PIN 修订及资料清理状态；未知确认结果保留本页面的原 UUID 和答案，允许重试。离开页面后先联网刷新最终状态，不自动重放家长确认。PIN 失效时隐藏资料，迟到响应不能恢复旧页面。
- 原有 `save_review_question` 不能直接绑定孩子提交草稿，必须走显式家长确认。父级旧辅助函数与上传/确认指纹表不向客户端开放。

## 导出、删除与统计

复用既有40类孩子导出，`ocr_records` 包含已提交的家庭记录、原始 OCR、孩子提交内容及家长确认信息，排除其他成员尚未提交的草稿；提交/确认审计也进入导出。孩子删除、账号删除和永久清理继续使用既有图片目录、级联和删除 UUID 屏障。

原有“超过24小时未入库的本人草稿”显式清理包含待家长确认的提交，界面已说明；不会因提交超过24小时自动删除。首次家长确认触发既有 OCR 校正统计；本迁移仍按一段 OCR 文本统计，手工标准答案不计作 OCR 字段。

## 验证与剩余范围

自动测试覆盖无 PIN 提交、原图上传、不可变模式/内容、回执隔离、家长确认、确认并发与重放、当前会话和实际授权到期、分页、导出及删除。截图检查覆盖360px中文正常/双倍字号；全量结果及 APK 见 [进度](PROGRESS.md) 和 [构建记录](ANDROID_BUILD.md)。测试使用本机数据库和模拟网络，不代表真实多设备验收。

后续迁移059已补齐[题干、选项、图片作答与批注的逐字段校对](OCR_FIELD_CORRECTION.md)，孩子提交及家长确认均保留字段内容，家长重新核对字段。显式标签分组仍需人工检查归属和真实教材验收。新流程未添加退回修改或云端提交通知，这两项不属于本次确认规则。
