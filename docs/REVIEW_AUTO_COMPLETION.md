# 复习全部作答后自动完成

更新：2026-11-05。补齐PRD验收项AC-11：新生成的自动复习任务在最后一题提交后自动完成，不再要求额外点击结算。迁移062及客户端已实现，尚未部署真实Supabase。

## 在线与离线行为

在线逐题提交仍由服务端使用冻结答案判定。最后一题的判题、复习排期、任务完成、逐题阶段奖励和钱包账本在一个事务中提交；任何检查失败都回滚本次最后一题，不留下“答完但结算丢失”的中间状态。全部答错也正常完成，阶段奖励为0。

逐题结果及金额保存在复习记录中，金币与XP仍按任务合计分别追加一条账本，保持PRD6.1的任务奖励幂等约束；无需另外点击完成。任务完成、奖励、最低时长和每日软上限规则继续复用迁移061及既有事务。

离线时，客户端把最后一个答案和自动完成命令放在同一个SQLite事务里保存。保存成功后列表与页面显示本机已完成、待服务端判题结算，钱包不变。部分作答继续计时；最后一题的完成命令使用相同操作时间和明确前序UUID。剩余队列容量不足两条或任一写入失败时，两条都不保存，用户可重试。

联网后服务端在判定最后一题时已经自动完成；队列内随后的完成命令返回`already_completed`并被确认，不再发奖。若最后一题回复丢失，重试原UUID读取既有回执。文件数据库重启、同答案重复保存和旧客户端重复调用完成接口均不增加奖励。

## 时间、权限与兼容

新任务保存`review_auto_complete=true`。迁移前已有任务默认false，保留显式完成约定；生成函数返回已有任务时不改其快照。客户端缺少此字段也沿用旧入口，支持迁移顺序和旧缓存恢复。

在线完成截止时间来自服务端。离线截止时间只由私有命令分派函数在租约、版本、前序关系、时间范围、成员访问检查通过后传入；客户端不能直接调用带截止时间的私有函数。有效时长在最后一题的操作时间停止，之后断网等待/上传延迟不计入学习时长。奖励日期与`completed_at`仍按服务端结算时间确定，避免设备改时发奖。

在线判题入口在锁任务前先锁定当前账号及家庭访问记录，与离线入口顺序一致。成员移除/账号删除须等待正在提交的事务；撤销完成后，旧成员连已完成答案的重放也会被拒绝。

最低有效时长不足时，最后一题和自动结算全部回滚；保留输入，达到时长后重试。任务级锁串行化两个设备的最后一题，同答案重试返回已完成记录，不再次推进复习或追加账本。被撤销的家庭、被删除的孩子或已清理的题目继续受现有权限/隐私规则约束。

自动完成字段随既有任务导出，不增加导出分区。原有阶段奖励、回执及孩子删除测试继续通过。

## 界面与验证

新任务显示“提交最后一题后自动完成，奖励由服务端确认”。最终提交成功才播放一次完成反馈；离线显示待确认，刷新不重复播放。旧任务仍可手动结算，正常/双倍字号下可滚动完成作答。

新增9项客户端和9组数据库检查；全量682项Flutter、359组数据库通过，核心覆盖率6125/6792（90.18%，102个源文件）。完整分析无问题，243个Dart文件格式及补丁检查通过。1项截图检查覆盖360px普通/双倍字号的输入、待确认和完成状态，已目视复核。

专项使用实际SQLite事务/文件重开和临时PostgreSQL双连接；后台断网90分钟的SQL用例使用特权时间夹具，验证有效时长仍为60秒。它不代表真实手机运行90分钟。原生实现未改，既有JVM与模拟器结果不重复计为本轮通过。
