# 错题与拼音列表分页

2026-11-05，按 PRD 第9节主要列表首屏目标，调整错题本与拼音词库的读取、滚动及离线查看。原列表须先读完全部500条分段数据，再进行本机筛选；现在按筛选条件请求首批最多50条，用户点击“继续查看”后再读取下一页。真实手机首屏1.5秒目标尚未测得。

## 范围与交互

- 错题和拼音分别读取；学科、掌握状态、归档状态和关键词在服务器筛选。关键词最多100字，停止输入300毫秒后检索，可匹配题目、知识点、语境、错误原因及其中文标签。`%` 和 `_` 按普通文字处理。
- 每页最多50条，按未归档优先、复习时间升序（空值末尾）、UUID排序。迁移060使用排序字段游标；同时间、空时间及归档边界均有回归，前页增加/删除记录不会导致偏移分页错位。
- 列表仅构建可见行；概览、筛选和题目可连续滚动。家长可跨已加载页选择最多100条；更改筛选会清空选择。大字号下将复习按钮、题目勾选与编辑操作放在正文下方。
- 加载后页遇到网络问题时保留已加载记录，提供重试。刷新或更改筛选后旧响应失效；页面销毁后不再更新状态。服务端权限拒绝会隐藏记录，不视为离线。
- 组卷仍使用原有完整题库读取；分页不截断组卷候选或孩子数据导出。标准答案仍在私有表，列表只返回当前权限可见的题目资料。

## 离线与权限

`ScopedQuestionCatalog`复用加密`OfflineStore`，按账号、孩子和完整筛选保存最近一次首批记录及服务器时间。每个孩子最多保留12个筛选的首批记录，每批最多50条；后续页不落盘。

仅网络失败允许读取相同筛选缓存，并显示“离线查看”、记录范围及同步时间。离线页没有“继续查看”，未缓存的筛选不会拿其他筛选冒充结果。未得到新服务器记录前，旧同步时间代表旧快照，不保证当前题目状态。

请求前后及缓存事务内核对账号、隐私版本、复习缓存版本、家庭权限、孩子删除状态和仓库生命周期。同一筛选后发请求使前次响应失效。孩子删除、成员撤销及复习清理会清除此缓存，迟到响应不能重新写回；账号退出沿用整账号清理。

响应校验包括账号/孩子/家庭、筛选、时间、条数、题目归属、删除状态、重复ID和下一页边界。修改、导入、家长确认、相似题采纳、复习、永久清理及账号切换同步使列表读取失效。
