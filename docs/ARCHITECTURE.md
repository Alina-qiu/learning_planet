# 架构说明

## 总体结构

[iOS运行诊断](RUNTIME_DIAGNOSTICS.md#ios诊断日志的原生策略检查)在MetricKit回调中只投影报告区间和崩溃/卡顿条目数量。NativeDiagnosticJournal共用账号边界、事件ID、去重、容量、过期和编码逻辑；原适配器仍在串行队列中读取/原子保存受系统文件保护且排除备份的日志。Swift策略检查与跨进程恢复验证直接编译生产代码，不替代MetricKit真实回调、锁屏文件保护或手机故障验收。

[家长调账明细](WALLET_ADJUSTMENT_DETAILS.md)通过迁移066以孩子/账本来源编号/审计动作严格关联原始wallet.adjust说明，并要求当前会话PIN；只读接口返回范围内的必要字段，沿用成员邮箱显示权限，不返回任意审计或幂等键。说明不持久缓存，账号/隐私/角色/授权版本变化丢弃迟到响应。四类奖励分页增加家庭时区，由客户端统一显示；旧无时区缓存明确标为本机时间。

[离线奖励页](OFFLINE_ECONOMY.md)在现有加密Drift中按账号/孩子/家庭/角色保存完整首批视图，每类50条。所有页面读成功才写缓存，权限错误不能被并行网络错误掩盖；写操作前后递增持久版本并撤销旧视图。恢复任务同步后刷新打开的离线页。持久兑换/调账请求沿用原回执协议，离线视图不产生钱包写入。

[已结束复习记录](REVIEW_RECORDS.md)复用原ReviewSessionScreen、Repository和账号范围内的加密缓存；首页与任务列表仅解除自动复习的终态导航限制，记录不调用开始/提交/结算接口。未作答题保留未作答状态，加载失败不显示底层异常；底部按系统导航栏高度留白。

[实际App复习联调](REVIEW_DEVICE_INTEGRATION.md)修复同一任务的后台刷新行为：复习任务Provider监听同步事件后invalidateSelf，保留输入表单；仓库替换仍通过依赖重载隐藏旧数据。同步中心用账号/孩子/任务组成的PageStorageKey保留展开状态，仅保存布尔值，数据刷新隐藏及账号隔离规则保持有效。

新增[本机联调工具](LOCAL_DEBUG.md)复用隔离的真实服务，原App通过USB端口转发访问127.0.0.1，Dart仅在显式development/debug配置下允许该HTTP源；正式配置继续要求HTTPS。普通与本机Android包名/数据分开，工具不会将服务端密钥放进APK。后端每次启动为新数据库，仅签名凭据稳定；任务等本机维护复用原SQL与Edge入口。

PDF任务通过迁移065与实际a4-v2生成器对齐：新建及新领取租约使用v2，已完成文件及有效旧租约保持原版本，完成接口继续严格校验。[真实PDF集成](PDF_INTEGRATION.md)连接实际App仓库、原Deno入口、Auth/Storage和S3，验证冻结快照、下载字节、丢失回执恢复及过期/关联删除；测试服务密钥不传给客户端。

清理worker在HEAD400时通过Storage元数据接口取得明确的对象不存在错误，其他错误继续保留任务重试；SQL再核查清单和元数据。新增[真实删除/注销测试](PRIVACY_INTEGRATION.md)使用原Deno入口、真实Auth/Storage与S3字节，核对孩子删除、依赖任务、Auth丢失回执和共享家庭保留。临时服务凭证仅留在服务端测试进程，客户端不接收。

图片测试补充[真实Storage/S3层](STORAGE_INTEGRATION.md)：复用真实Auth及受限PostgREST连接，在应用迁移前运行官方Storage迁移；原App媒体仓库经 `/storage/v1` 代理访问Storage，再由受限数据库连接校验RLS、实际MinIO保存字节。测试验证原图/处理图、PIN确认、私有访问及稳定上传路径重试；仅用于临时回环环境，不改变生产技术栈或APK配置。

账号测试补充[真实GoTrue/SMTP层](AUTH_INTEGRATION.md)：受限Auth数据库角色运行官方迁移，真实服务签发用户会话，App原有登录仓库调用验证码和刷新接口，再由PostgREST执行家庭/PIN操作。SMTP只接收本机合成测试邮件；版本/模板参数来自项目配置。Windows测试工具有独立监听适配，CI使用官方Linux包；服务、测试会话及密钥均不进入APP产物。

测试增加[本地真实 HTTP 层](HTTP_INTEGRATION.md)：App 的 Supabase SDK/Repository → 仅转发 `/rest/v1` 前缀的回环代理 → PostgREST → 全量迁移的隔离 PostgreSQL。与直接SQL检查共用数据库引导，固定PG15.19并在迁移前校验实际主版本与Supabase配置一致；CI检查PostgREST16.2/16.5。授权使用临时签名JWT及受限连接角色，未模拟真实Auth/Storage服务，不进入APP构建产物。

[家庭时区设置](FAMILY_TIMEZONE.md)通过迁移064的独立版本字段及管理员PIN接口提交，幂等比较与家庭级锁防止旧请求覆盖、生成读取过渡日期；已有任务和账本保持原值。客户端先使家庭/计划/提醒读取失效，家庭缓存事务内再次检查代次，原生提醒暂停后按新策略恢复。离线任务队列保持不变，已确认同步快照的时区变化驱动家庭资料重读，避免跨设备继续显示旧时区。其他离线设备的本地提醒不能即时更新。

[孩子作答把握](REVIEW_ANSWER_CONFIDENCE.md)通过迁移063独立存储为可空的1–3整数；内容编辑清空当前值，过期任务不能覆盖当前题目。在线保留原四参数并增加无默认值的五参数RPC，离线字段进入原命令指纹，答案/把握/最后结算共用事务与账号/家庭访问锁。新队列以家庭日期、错误次数、把握（未知最后）及UUID排序，冻结顺序和前次把握。新增列沿用导出及级联删除。计划奖励编辑改为结构化草稿表单，仅验证/序列化当前可见规则，保持既有JSON与服务端结算合同。

[Android10前台ANR诊断](RUNTIME_DIAGNOSTICS.md)在Application生命周期与串行日志线程中接入系统错误状态查询，只读取主进程PID/名称/condition。新范围、前台和时钟边界后先观察健康状态，同一异常持续期间沿用一个事件ID，确认不删除去重标记。与既有Java未捕获异常路径共用账号scope和固定字段日志，API30以上继续读取退出历史；无新数据库迁移。故障测试源集仅在显式legacyAnrFixture属性下编译，使用独立应用ID，普通APK校验排除测试类和入口。

[复习自动完成](REVIEW_AUTO_COMPLETION.md)通过迁移062保存任务完成方式，新任务最后一题判定、排期、逐题阶段奖励及既有任务完成事务一起提交。在线入口先持有账号/家庭访问锁再锁任务，与离线入口一致，成员移除不能跨过正在提交的结算。公开判题接口使用服务端时间，私有离线分派在租约/版本/时间校验后传入操作截止时间；上传等待不计入时长。客户端最后答案与后继完成命令在一个SQLite事务中保存，生成待确认状态，后继命令允许服务端已完成的幂等回执。旧任务仍支持显式完成。

[复习阶段奖励](REVIEW_MILESTONE_REWARDS.md)通过迁移061将新任务标为规则2，冻结题目阶段/排期；旧任务保留规则1。服务端只有在内容版本、阶段和到期时间匹配时才推进复习并记录阶段奖励资格；全部完成时按题目ID顺序取得题目/版本/阶段唯一回执，逐题金额与既有钱包/软上限事务一并提交。离线只保存答案和命令，不计算可入账奖励。原有导出含新增字段，私有回执随对应数据级联删除。

[任务完成反馈](TASK_COMPLETION_FEEDBACK.md)在普通任务/复习持久完成调用成功后触发，离线只声明记录保存，刷新和同步重放不触发。怪兽能量从当前孩子和家庭日期的任务列表派生，不存为资产或参与账本。设备偏好仅保存声音/动画两项布尔值，读取失败关闭效果；系统减少动态效果优先，声音失败不影响已完成操作。

[错题与拼音列表分页](QUESTION_CATALOG_PAGINATION.md)通过迁移060按筛选和归档/复习时间/UUID游标读取，每批最多50条，Flutter仅构建可见行。加密缓存按账号/孩子/筛选保存最多12个首批快照，断网显示同步时间且不提供未缓存的后页；归属、读取序号、隐私/复习版本及仓库生命周期阻止迟到响应恢复已清理数据。组卷完整选题及原有导出不截断。

[OCR逐字段校对](OCR_FIELD_CORRECTION.md)保留全文与行级来源，设备端按明确标签尝试分成题干、选项、图片作答与批注，未知归属由用户调整并逐字段确认。迁移059在原有保存/家长审核事务内验证字段，冻结首次校对快照，并按0至4个非空原始字段统计校正率。题目只组合题干和选项，图片作答不自动成为判题标准答案；旧OCR按原有一段文本口径兼容。

[孩子录入与家长确认](CHILD_QUESTION_SUBMISSIONS.md)通过迁移058复用私有OCR草稿、图片桶及上传指纹，孩子提交只存待确认内容。当前会话PIN授权的家长显式确认标准答案后，才调用既有题目保存逻辑并关联OCR；草稿行锁与私有请求指纹防止重复入库。提交前后范围校验、分页、原始提交保留、审计及原有40类导出/删除边界均有回归；迁移059进一步接入结构化OCR逐字段校对。

[家长计时纠正](TASK_TIME_CORRECTIONS.md)由迁移057在任务行锁内校验同步版本、当前会话PIN和实际授权到期时间，累计秒数变更由既有触发器推进版本，并追加审计。私有请求回执防止重放重复修改；旧离线任务命令进入原冲突流程。客户端在线读取、冻结页面内的原请求并核对账号/授权/隐私范围，不增加离线家长操作队列，任务完成与金融状态保持原值。

[商城与经济历史分页](ECONOMY_PAGINATION.md)通过迁移056的时间/UUID游标有界读取四类列表，首批每类50条；Flutter仅构建可见行，各列表独立继续查看。响应与账号/孩子/家庭/筛选绑定，刷新、经济操作、授权变化及隐私清理隔离迟到页。原库存/限次、过期退款和服务端账本规则保留，不新增离线金融状态，完整导出仍包含全部历史。

[大厅角色与离线成长](OFFLINE_GROWTH.md)使用统一静态预览，迁移055在只读成长接口中加入归属和服务端时间。`GrowthSnapshots`完整保存账号/孩子加密快照，仅网络失败可回退；版本和读取序号隔离装扮/家长奖励修改、旧读取和隐私清理，离线XP不参与解锁。成长更换保持在线，不增加奖励或装扮离线队列。

[任务补充说明](TASK_NOTES.md)独立于任务状态和打卡队列。迁移054按家庭权限提供当前正文与服务端版本，私有回执用账号/UUID/正文哈希和事务取消屏障处理回复丢失；重放旧成功请求只返回最新正文，不重复覆盖。客户端加密保存共享缓存、草稿和原请求，只有显式共享才发布；孩子/成员/账号清理及仓库失效阻止迟到响应恢复数据。孩子导出扩展为40类。

[计划离线查看](OFFLINE_SCHEDULES.md)通过迁移053的游标分页同时读取模板、长期计划及进度。完整读取后才保存加密账号/孩子缓存；仅网络错误可回退并显示时间。仓库修改版本与读取序号隔离过期响应，既有孩子/家庭权限/账号清理覆盖新缓存键；不新增离线计划写操作或本机奖励结算。

[家庭概览](FAMILY_OVERVIEW.md)通过迁移052在单次只读请求内汇总当前家庭全部孩子的七日任务和待处理事项，不下载历史明细或触发奖励/退款。客户端按家庭PIN及账号隔离，可在全部/单个孩子之间筛选并进入对应处理页；统计沿用学习报告的家庭日期和请假排除口径。

[经济操作恢复](ECONOMY_COMMANDS.md)将兑换申请和家长调账绑定到账号/孩子的单项加密请求。迁移051在同一事务内执行业务规则并保存私有回执，提交/停止通过请求锁串行；客户端只显式核对/重试/停止，页面重开不自动发起金额变动。孩子/成员/账号清理删除待办，迟到响应不能恢复；钱包仍完全由服务端追加账本投影。

[邮箱验证码登录](EMAIL_LOGIN.md)使用临时、无持久化的Auth客户端接收校验结果，主仓库检查页面/账号版本后才恢复新鲜会话，避免超时或离开页面后的旧校验覆盖当前登录。主SDK继续负责安全存储和家庭页面切换；邮件模板及验证码参数随本地Auth配置保存，托管项目需要另行配置。

迁移049–050提供[家庭成员、邀请与移除](FAMILY_MEMBERS.md)：成员列表只在当前家庭PIN有效时联网读取，邀请及移除共用加密的单项请求、固定UUID与私有服务端回执。邀请接受/撤销和成员移除锁定同一家庭，分别比较邀请/成员版本；任务快照和命令持有家庭共享锁，防止移除后留下新租约。客户端schema5持久保存按账号/家庭的成员状态、最后撤销版本和通知清理待办，前台进入/恢复及每15秒核对；清理仅影响对应账号和家庭，不写全局孩子删除标记。重新加入后旧队列/图片回调仍不能恢复旧资料；离线设备不能即时获知撤销。

目标设备包括华为鸿蒙4.2和iPhone。迁移045与`parent-push`提供HMS/APNs远程通知服务端，私有注册/队列不向普通查询暴露Token。Flutter完成两阶段注册、版本化匿名撤销和前台续期；Android HMS/iOS APNs原生接收器校验不透明消息后显示固定文案。功能默认关闭，真实服务及两端验收仍待完成，见[远程通知协议](PARENT_REMOTE_PUSH.md)。

任务提醒由迁移047提供家庭时区/安静时段，Flutter负责范围及候选更新。Android通过MethodChannel交给自有AlarmManager接收器，串行持久保存最多60个不透明ID及时间策略，投递前复查并消费记录；接收器不打开账号数据库或Flutter引擎。iPhone按用户“优先安静”的选择使用[远程任务提醒](TASK_REMOTE_PUSH.md)：迁移067/068提供按账号/家庭/当前孩子绑定的独立设备注册与短时队列，Edge在发送前复查，APNs以data-only投递；Swift收到后根据服务器校准时钟、当前范围、本机有效时点和两份安静策略再决定是否提交即时通知。退出/切换先关闭原生接收，迟到注册及消息不能越过版本边界；iOS不再设置任务本地定时通知。后台唤醒与系统最终展示仍受操作系统限制，真实投递和安静边界需要签名手机验收。

迁移048的[复习队列稍后提醒](REVIEW_REMINDERS.md)复用同一提醒候选与原生排程，每任务一条预约，使用任务行锁、命令重放与修订号防止重复和旧请求覆盖。Flutter预约变更先清理当前计划，并在变更前后更新账号/孩子的持久缓存版本，隔离迟到响应；请求不明确和本机排程失败分别重试。预约不改变复习题目、日期或奖励。

任务提醒开关、静默区间和已读回执同样经过该缓存版本校验。仓库通过注入的原生取消接口先撤下当前孩子的计划，再发送写入；不影响家长消息范围，失败不回退旧候选。设置界面将服务器保存和本机排程分别显示并重试，详见[本地提醒](LOCAL_NOTIFICATIONS.md)。

家长学习报告的业务指标由PostgreSQL从账本、兑换与首次OCR确认元数据聚合，客户端只展示并校验范围（迁移040）。孩子删除的文件清单同时支持已核实归属的家庭目录和旧孩子目录，旧草稿UUID屏障防止迟到上传重建（迁移041）。详细口径见[业务指标](BUSINESS_METRICS.md)与[孩子删除](CHILD_DELETION.md)。

迁移042将首次开始的设备模式写入任务，来源随原普通/复习命令持久化；状态、版本与来源同事务更新，使用原回执防重，不新增独立身份或事件表。家长报告据此计算[自主开始率](TASK_START_METRICS.md)，历史未知值不回填。

迁移043增加家庭首任务队列和首周活跃日期。前台生命周期采样先进入按账号加密的有界队列，再按家庭日去重上传；共享数据不保存孩子/账号/设备标识。成熟队列汇总仅限服务端，家长报告展示本家庭的[次日/第7日回访](FAMILY_RETENTION.md)，历史缺失不冒充零留存。

迁移044的[家长配置用时](PARENT_CONFIGURATION_TIME.md)从真实编辑窗口采集单调时钟区间，经按账号加密的有界队列上传，独立于业务保存请求。PostgreSQL先按家长合并重叠区间再聚合家庭用时，跨日按报告时区裁剪；孩子/账号删除和成员移除时清理，90天保留任务由部署脚本配置。

```text
  └─ Supabase Client
        ├─ Auth
        ├─ PostgreSQL + RLS
        ├─ Storage
        └─ Edge Functions / Cron
              ├─ 每日错题复习任务
              ├─ 奖励事务
              ├─ AI 分类/相似题建议网关（默认关闭）
              └─ PDF 生成
```

## 模块边界

- `auth_family`：身份、家庭、成员、孩子和家长 PIN。
- `ai`：默认关闭的设置、持久请求、分类建议、相似题检索/生成与审核采纳；统一网关与共享额度/保留，数据库精确算术复算、采纳回执及来源/反馈，见[AI分类建议](AI_ANALYSIS.md)及[相似题](SIMILAR_QUESTIONS.md)。
- `tasks`：模板、实例、计时、长期计划和提醒。
- `wrong_questions`：错题、复习调度、自动任务和组卷。
- `economy`：钱包、账本、XP、软上限和审计。
- `rewards`：商品、申请、冻结、审批和履约。
- `reports`：规则聚合日/周/月报、任务分类快照驱动的五维活动趋势和学科知识点分布；AI周报复用共享网关，服务端核对并冻结最小统计，提供逐条数据依据与幂等反馈，快照随AI正文一起清理。
- `notifications`：家长消息、个人偏好、加密设备模式和前台提醒；迁移038提供消息/回执，039提供最长168小时的离线同步异常策略，045提供私有设备注册和派发队列。Flutter管理注册/撤销，HMS/APNs原生接收器独立校验范围、期限和静默后显示固定文案；后台功能默认关闭，真实送达待验收，详见[家长消息说明](PARENT_NOTIFICATIONS.md)。
- 同步：`core/offline`持久队列与清理，`tasks`仓库/同步中心负责任务及复习命令、冲突核对与诊断摘要，`wrong_questions`负责图片草稿/上传；中心沿用各仓库的账号、孩子与家长PIN边界，不产生新奖励或自动上传诊断。
- 运行指标：`core/diagnostics`单独记录固定分类的HTTP耗时、同步结果和主isolate Dart错误，使用加密缓存及前台有界上传；迁移037负责私有去重回执、匿名每日汇总和AI确认终态计数。它不上传同步中心的文字摘要，运维汇总仅服务端可读；范围与保留策略见[运行诊断说明](RUNTIME_DIAGNOSTICS.md)。

## 不变量

1. 客户端不能直接修改钱包余额。
2. 每个奖励结算操作必须具有唯一幂等键。
3. 同一孩子同一天最多一条 `automatic_wrong_review` 任务。
4. 自动复习任务开始后，题目集合不可变。
5. 家长调账和补签必须有审计记录。
6. AI 输出不能直接改变金币、任务完成或掌握状态。
7. 所有儿童数据按家庭 RLS 隔离。
8. 生产数据库必须使用设备密钥加密；密钥异常保留文件并停止启动，禁止明文回退或自动重建。

本机存储、凭据迁移、异常恢复及原生验收边界见[本机数据保护](LOCAL_DATA_SECURITY.md)。

## 同步策略

本地先写入命令队列并给予界面反馈。服务端接受命令后返回权威版本；普通文本采用最后写入优先，任务完成和积分使用幂等命令与追加账本，兑换使用服务端事务。发生无法自动合并的内容冲突时保留两版并交给家长处理。

## 自动错题复习任务

定时函数使用家庭时区计算业务日期，并为每个孩子调用 `generate_daily_wrong_review_task(child_id, date, max_questions)`。数据库唯一约束负责最终防重。App 每次从离线恢复时可调用同一 RPC 作为补偿；由于 RPC 幂等，不会重复创建。生成后的题目通过 `task_review_items` 保存快照。
