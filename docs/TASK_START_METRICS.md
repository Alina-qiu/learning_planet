# 自主开始记录与统计

对应PRD第11节“无家长代操作且在时间窗内开始的任务 / 可执行任务”。迁移042为普通任务与自动错题/拼音复习记录首次开始时的设备模式，并把指标接入家长日/周/月报告。它是使用行为记录，不识别真实操作者，不作为发奖、扣分或权限依据。

## 开始来源与页面行为

| 来源 | 何时记录 | 展示与统计 |
|---|---|---|
| `child_mode` | 已知家庭范围，点击时处于孩子模式 | 在任务时间窗内首次开始才进入分子 |
| `parent_assisted` | 点击时处于该家庭的家长模式 | 按钮显示“家长代开始”或“家长代开始复习”；不计为自主开始 |
| `unknown` | 旧客户端、不带来源的原接口、家庭范围缺失或家长模式范围不匹配 | 明确列为未知，不能推断为孩子自主开始 |

来源在点击时取值，不从之后同步时的设备模式或当前PIN授权反推。家长PIN过期不会把仍处在家长模式的开始改成孩子模式；家长特权仍由原授权链路控制。退出家长模式后，新任务才按孩子模式记录。主界面、任务中心、错题库和同步中心打开复习时都传递家庭范围。

服务端使用 `task_instances.start_origin` 保存来源，`start_observed_at`保存服务端首次受理时间，原`started_at`仍为首次开始的业务时间。首次开始后，暂停、继续、完成、放弃及后续更新均不能重写来源和受理时间。历史已开始任务保留unknown，不根据当前模式、操作者账号、任务完成情况或当前PIN进行回填。

## 时间窗和分母

报告先选择当前孩子、报告到期日期范围内的已生成实例，剔除长期计划已批准请假。主动放弃、跳过和过期仍留在统计队列中。

1. 优先使用实例快照的`scheduled_at`与`due_at`；缺失端点分别采用家庭当日00:00和次日00:00，支持夏令时的23/25小时日。
2. 开始端点不晚于服务端当前时间，且截止晚于开始的实例，才属于当前“可执行任务”分母。尚未开启的时间窗单列，历史报告不是当时状态的快照。
3. 分子为`child_mode`且`started_at >= 开始端点 && started_at < 截止端点`的首次开始。恰好到截止时刻及提前开始均不计入；应用仍允许原业务规则允许的开始操作，不因统计窗口新增限制。
4. 可执行任务分解为：窗内孩子模式、窗外孩子模式、家长代开始、来源未知、未记录开始，五项之和等于分母。
5. 分母为0、存在未知来源的已开始任务或无效时间窗时，`rate`为null；页面说明无数据或记录不完整。不会把未知记录当成未自主开始后显示0%，也不会从分母中悄悄删除未知记录。

“未记录开始”也可能包含家长直接补签完成，不能据此评价孩子是否学习。当前分母仅包含系统已生成的实例，不推算尚未生成的历史任务。指标用于一起调整安排，不用于排名或惩罚。

## 离线协议、重放与竞争

新客户端普通开始和复习开始分别在现有`start`/`review_start`命令中写入`start_origin`枚举。命令UUID、服务端校准时间、缓存租约、前序命令和来源先写入同一个加密、账号隔离的持久队列，重启、网络恢复和响应丢失后重发原载荷。非开始命令不接受该字段。

迁移042保持原命令的租约、时钟范围、版本冲突、前序依赖、判题和奖励校验。普通命令回执保存原载荷；复习回执仅保存包含来源的请求摘要与时间。相同UUID改变来源被拒绝；两个设备竞争开始时只有成功的一次确定来源。记录来源与任务状态在同一UPDATE中完成，只推进一次同步版本，避免后续命令因额外指标写入发生冲突。

旧的`start_task`、不带来源的普通/复习命令仍可使用，记录unknown。新在线适配器使用`start_task_with_origin`；新客户端写入需先部署迁移042，不会在服务端不支持时丢弃来源并改写待同步命令。客户端读取没有此指标的旧报告时仍可展示原报告内容。

## 权限、隐私和验证

- 开始仍要求当前账号可见孩子；来源只是客户端声明的模式，不授予家长权限。客户端不能直接更新任务统计列。
- 报告继续要求当前会话家长PIN；账号/PIN变化时隐藏结果。客户端校验统计版本、非负整数、分项合计与比率一致性。
- 两个新增字段随`tasks.csv`导出，该迁移不新增类别；当前迁移048后的ZIP共39类CSV。孩子/账号删除沿用任务和命令回执清理，没有新建独立行为身份表。
- 不记录额外姓名、题干、答案、图片或设备标识。设备模式不能证明实际操作者；离线时间仍是现有服务端租约允许范围内的客户端记录，不是防篡改考勤证明。

`scripts/test_task_start_metrics_cases.mjs`覆盖实际在线/离线RPC、重放与载荷变化、两连接竞争、复习判题与来源保留、时间窗/夏令时/请假/未来窗口、未知与无效数据、导出/删除及权限。`test/task_start_metrics_test.dart`覆盖模式/PIN变化、真实SDK参数、磁盘重启、响应丢失、账号隔离、复习队列及页面行为。

部署按序应用001–042，无新Cron或供应商依赖。本轮仍未连接真实Supabase；实际家庭使用、Android/iOS跨端同步和设备时钟验收待完成。完整结果见[测试说明](TESTING.md)。
