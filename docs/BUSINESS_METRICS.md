# 业务指标与统计口径

对应 PRD 第11节。现有学习报告覆盖任务完成率与复测正确率；迁移040补充兑换履约中位时长、金币产消比和OCR校正率，迁移042补充[首次开始来源与自主开始率](TASK_START_METRICS.md)，迁移043补充[家庭次日/第7日回访](FAMILY_RETENTION.md)，迁移044补充[家长配置用时](PARENT_CONFIGURATION_TIME.md)。八项均有本地实现与测试依据，云端及真实家庭验收尚未完成。没有接入外部埋点平台。

## 需求覆盖

| PRD指标 | 当前实现与证据 | 尚需完成 |
|---|---|---|
| 次日/7日家庭留存 | 迁移043冻结家庭首任务与时区，采集前台活跃/7日离线补传，家长报告及服务端成熟队列统计；历史/缺失单列 | 云端、真机多端与真实家庭覆盖率验收；超期离线、错误时钟或删除本地样本可能缺失 |

| 任务完成率 | 当前孩子、到期日队列内已完成实例/应完成实例，剔除批准请假 | 真实家庭及两端验收；未生成实例不在现有统计分母内 |
| 兑换履约时长 | 本期实际履约记录的申请至履约中位时长，附样本数 | 云端/真机验收 |

| OCR校正率 | 首次确认时被修改的OCR字段数/确认的OCR字段数 | 真实图片识别质量；历史缺少首次确认数据的记录不补算 |
| 金币产消比 | 按入账时间的金币收入/已履约金币消耗，冻结与退款排除 | 家庭经济规则校准；不自动调价、扣分或奖励 |

## 时间、样本与空值

报告沿用服务端家庭时区与日期边界：日报一天，周报截至所选日期的7天，自然月报为整月（当前月截至今天）。数据库使用当地日期的两个午夜转换为时间戳，包含下界、排除上界，覆盖夏令时的23/25小时日。请求仍需当前会话的家长PIN。

- **履约中位时长**：选择 `status=fulfilled` 且履约时间落在报告期间的记录，时长为 `fulfilled_at-created_at`。可以包含此前申请；排除履约时间缺失或早于申请的异常记录。偶数样本取中间两项的平均值，奇数样本取中间值。未履约、拒绝、取消不计为零。另列“本期申请中目前仍待履约”的 requested/approved 数量，它是当前状态，不能用来还原历史某日的待办快照。
- **金币产消比**：与原报告金币收入和履约消耗使用同一账本聚合结果。收入包含已入账任务/活动奖励及家长正向调账；冻结、退款不算新产出或消费，人工等其他扣减单列。消耗为0时返回null并显示“暂无履约消耗”；有消耗但收入为0时显示 `0.00 : 1`，不混同于无数据。
- **OCR校正率**：按本期首次确认时间选择已保存且不在删除中的OCR草稿。迁移059及[逐字段校对](OCR_FIELD_CORRECTION.md)对题干、选项、图片作答、批注四个非空原始字段分别计数；旧未结构化OCR仍按一段文本计数，历史值不重算。学科、手工标准答案、解析、知识点和错误原因不属于OCR字段。比较原始与首次确认字段时只去首尾空格，内部空格、换行及标点的变化都算一次字段修改；它不是字符错误率或模型准确率。

OCR分母为0时返回null。识别失败后手工录入记录有确认时间，但识别/修改字段均为0，单列手工条数。已保存但没有首次确认统计的历史记录只列当前孩子的总缺失条数，不计入任何时期的校正率；不猜测它们当时是否被修改。

## 来源冻结、清理和导出

迁移040增加首次确认统计，迁移059扩展至最多四个识别字段并保存首次校对快照 `final_ocr_fields`。触发器仅在 recognized/manual 首次转 saved、绑定当前孩子题目时记录。保存重试、后续题目编辑、原图清理或其他草稿更新均保留原值；客户端不能直接写统计列。原始识别与最终校对字段保存在同一OCR记录，没有新增图片或模型请求。

字段随现有OCR记录导出为 `ocr_records.csv` 中的新增列，该迁移不新增CSV类别。当前导出共40类，见[孩子数据导出](CHILD_DATA_EXPORT.md)。错题进入永久清理时立即退出OCR指标；实际删除时统计字段随草稿删除。孩子删除受理后不可再读取报告，账号注销沿用已有家庭/孩子清理。不用当前编辑题干反向重算历史。

`learning_report`仍为只读聚合，既不写钱包和任务状态，也不发起AI请求。旧内部报告函数和触发器入口撤销客户端执行权限；新入口校验会话PIN和孩子可见性。客户端还核对回包的孩子、周期、统计版本、非负数量及校正率一致性；账号切换或PIN失效后不展示迟到结果。报告不写本机业务缓存。原AI周报继续使用原有最小白名单事实，未扩大模型输入。

## 验证与部署

按序应用迁移001–059；逐字段统计无需新Cron或供应商配置。旧客户端忽略新增汇总字段，新客户端也可读取没有新增指标的旧报告。存量已保存OCR记录不回填统计；新结构化OCR保存需要新版逐字段确认内容。

- `scripts/test_business_metrics_cases.mjs`：6组真实临时PostgreSQL检查，覆盖中位数及离群值、日/周/月与夏令时边界、冻结/退款/人工扣减、零样本、首次确认与重试、编辑不追改、手工/历史排除、权限、导出、清理和孩子删除。
- `test/business_metrics_test.dart`：9项客户端检查，覆盖真实Supabase SDK请求、范围/账号切换、非法指标、空值与零值区分、360px/两倍字号、PIN失效和重试时的旧结果清除。

最新全量验证见[测试说明](TESTING.md)。本轮未连接真实Supabase；设备、云端与真实家庭的数据口径验收仍待完成。
