# 图片导入中断与草稿范围

日期：2026-11-06，对应PRD ERR-01/ERR-02、本机草稿及逐张校对流程。

## 修复的问题

单张相册或拍照导入此前先处理图片，再保存本机草稿。图片解码、旋转或裁剪失败，或用户在处理完成前离开页面时，选中的原图没有落盘。家长录入页只核对家庭PIN，也可能把等待期间返回的旧图片写入同家庭的新登录账号。

修复前分别用实际页面、草稿仓库和文件SQLite复现：处理失败后草稿数为零；切换账号后，迟到图片出现在新账号下。日志为`tmp/ocr-interruption-reproduction.log`和`tmp/ocr-interruption-account-reproduction.log`。

## 现在的行为

- 选图返回后，先保存原图、图片处理设置和未同意上传的草稿，再开始处理。原图保存失败时停止处理，页面保留错误说明。
- 处理失败或处理期间退出页面，已保存的原图仍可从本机草稿打开、重试。页面关闭后的处理结果不再访问已销毁的页面或覆盖草稿。
- 家长和孩子录入均绑定首次操作时的仓库、账号及资料清理版本。选图或处理返回后重新检查；账号改变、资料清理或家长PIN到期时，不接受旧结果。
- 排队保存的编辑开始写入前再检查绑定范围。未切换账号时，已排队的编辑可以在离开页面后保存；不能在等待前一笔写入结束后转入新账号。
- 旧范围的图片和校对表单不继续显示。仅PIN到期时继续显示“校对草稿已保留”，重新验证后可恢复校对。

变更在`lib/features/wrong_questions/presentation/question_ocr_screen.dart`。原图草稿仍处于`editing`，未经同意和完整校对不会进入上传队列；孩子提交仍须家长确认标准答案。未修改服务端、奖励规则或原生识别引擎。
