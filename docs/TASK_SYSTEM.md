## PIN 授权边界

- 验证成功后授权绑定家庭、用户和 Supabase JWT 的 session_id，有效期 10 分钟。
- 管理 RPC 和内容写入 RLS 在服务端检查授权；本地 bool 不能代替服务端授权。
- 家庭邀请详情和审计日志的读取同样需要有效 PIN 授权。
- 退出家长模式、切换孩子、退出登录时撤销当前会话授权；网络失败会提示重试，不宣称已撤销。
- 首次设置 PIN 要求管理员在登录后的 5 分钟内操作；设置后仍需验证才能获得授权。
- 更换 PIN 会撤销其他会话的授权；连续五次失败锁定十分钟。
- 按用户明确授权，普通家长在有效 PIN 会话授权内可配置任务和计划、补签并触发任务及计划规则内的金币/XP奖励。补签原因必填并审计，重复完成不重复发奖；不能直接修改钱包、账本或取得管理员专属权限。迁移 009 扩展补签权限，尚未部署到线上。
- 这不是独立孩子登录身份。当前家庭成员仍能读取家庭内孩子的数据；独立儿童账户和更细的读取隐私不在本次交付中。

## 使用入口

首页“任务管理” → 右上角日程按钮 → “周期模板、长期计划与提醒”。家长授权有效时可新建配置；未授权或到期后为只读。

支持一次性、每天、每周指定星期、自定义日期，以及开始/结束日期、家庭时区内的开始/截止时间、单次金币/XP、最低有效分钟数和目标时长（1–1440分钟且不少于最低时长）。目标时长用于提示，超时不扣分。每周未选择的星期为休息日。最长配置跨度 366 天。编辑只影响后续实例，已生成的任务保存原规则快照；模板可启停。

任务类别为必须、推荐、挑战，列表先展示未结束任务，再按日期、类别、建议开始时间排序；类别仅影响标识和顺序，不改变奖励、不产生惩罚。类别“挑战”与每日唯一挑战任务是两个概念：把普通模板标为挑战不会获得每日挑战的固定奖励。历史实例缺失目标时长时不补猜；已有每日挑战标为挑战，新自动复习按题数×2分钟显示目标。

## 放弃与恢复

任务页及自动复习页提供确认后放弃。未开始、进行中、暂停中的任务可转为独立的`abandoned`终态；停止计时并保留已累计有效时长，取消本次任务的提醒，不发完成奖励，也不扣既有金币或XP。已完成/跳过/过期任务不能放弃。后续日期的重复任务照常生成。

孩子不能恢复或修改终态。家长可在有效会话PIN下填写原因补签普通任务，保留审计；自动复习不能通过补签绕过作答。放弃的普通任务保留在报告和长期计划完成率分母，实际有效时长保留，不计完成次数和阶段奖励。补签后按正常规则结算一次。

复习中途放弃保留已提交题目的判定和复习排期，未答题仍待复习；整次复习没有完成奖励。当日不会生成另一份复习替代它，下一家庭日期重新选取到期题。后来永久删除源题时会清除正文和答案，保留“已放弃”历史状态。

长期计划创建后锁定规则，支持批准当日及未来未开始任务的请假。完成率分母包括尚未生成的应完成日期，排除批准请假日；漏开应用不会降低分母。阶段奖励按完成次数发放一次，到期终奖只取达到的最高完成率档，不累计各档。

阶段奖励输入示例：`3:20:30,7:50:50`，含义为完成 3 次奖励 20 金币/30 XP，完成 7 次奖励 50/50。更高终奖档位示例：`90:200:200,100:300:300`；百分比必须高于基础达标率。

## 提醒

家长端新增独立的[家长消息与前台提醒](PARENT_NOTIFICATIONS.md)。在家长消息中启用该设备当前家庭的家长提醒模式后，清除孩子任务通知并只显示兑换申请、同步异常与周报；可显式切回孩子任务提醒。未来任务本地排程与家长远程通知分开；[HMS/APNs接入](PARENT_REMOTE_PUSH.md)已有代码，真实配置与送达尚未验收。

提醒设置内可以关闭提醒、设置静默时段，并显式申请 Android/iOS 系统通知权限。服务端按家庭时区计算开始前 10 分钟、开始时、截止前 15 分钟三个候选时点，相同时间合并，静默时段过滤，已读不再返回。

预计算未来七天提醒，不提前生成未来可领奖任务。设备调度最近 60 个未来时点；打开应用、回到前台、任务或提醒刷新时同步。完成/放弃/跳过/已读和设置关闭后取消对应待调度通知；切换孩子和账号清理旧通知。锁屏正文不显示孩子昵称、任务题目等信息。Android 使用非精确闹钟，不申请精确闹钟特殊权限。

提醒RPC按合并时段返回任务ID、模板ID和日期。已缓存提醒可在网络中断时结合本机未同步终态过滤，保留同一时段其他任务及后续日期的模板提醒。缓存保存原始候选，冲突采用服务端非终态后可恢复提醒；明确拒绝访问会清除缓存和设备待调度通知，不能作为网络失败回退。孩子删除/账号注销同时清除提醒缓存。

当前为本地通知而非远程推送。另一台设备修改任务时，当前设备在下次同步前仍可能显示旧提醒；离线期间的新计划不能自动到达本机。操作系统节电策略可能延迟通知，需要真机验证。

2026-11-05补齐生产启动清理及系统权限复查。迁移047返回家庭时区和安静时段；Android任务提醒改由自有AlarmManager接收器投递，在实际显示前再次校验静默区间、时钟、范围及15分钟有效期。重复广播不重复显示，重启只恢复未来候选，不补发错过的提醒。旧插件定时接收器已从清单移除，避免升级前的计划绕过校验。iOS仅增加前台拦截代码，后台系统显示的延迟边界仍未解决，且尚未编译验证。证据及限制见[本地提醒验证](LOCAL_NOTIFICATIONS.md)。

## 部署与定时作业

1. 在目标开发/staging环境审查并应用尚未部署的迁移005–012。先核对目标；不要用db reset操作线上数据。离线需要010，复习需要011，OCR和图片管理需要012。
   新版客户端还需按顺序应用全部后续迁移至025。024单独提交枚举扩展，025才引用`abandoned`；不要把两份SQL拼为同一事务。025扩展提醒RPC返回列，请在客户端升级前部署数据库；旧客户端未识别新终态，不能与已启用放弃功能的新客户端混用。
   本版完整功能需继续按序应用至047；047为提醒增加`delivery_policy`。缺少策略的旧缓存不会继续排程，会清理待发计划并提示联网刷新，服务端部署必须先于客户端升级。
2. 迁移 008 在 pg_cron 已启用时注册每五分钟维护作业：按家庭当天幂等生成任务并结算已结束计划。
3. 若迁移时尚未启用 Cron，审查后在目标 Supabase 环境运行 `supabase/operations/enable_task_maintenance.sql`。本次没有执行该线上操作。
4. 检查 cron.job 与 cron.job_run_details，确认作业注册和执行结果。
5. 系统维护函数只允许数据库调度者或 service_role 调用，普通登录用户不能伪造系统上下文。
