# 相似题、规则复算与家长采纳

对应 PRD ERR-05、PDF混合选题和7.2输出审核。迁移034、Flutter及现有`ai-analysis` Edge入口已实现；本地模拟验证不代表真实模型教材质量、云端部署或Android/iOS验收。AI网关仍默认关闭，未配置或调用真实供应商。

## 使用流程

错题本 → 普通错题旁“相似题”，需要当前家庭有效家长PIN。

1. 从当前孩子未归档、未删除的题库查找：优先同学科且知识点文字相同的题，其余明确标为“同学科候选，需核对关联”。关键词在题干/知识点中匹配，最多20题；不是跨家庭检索、外部题库或语义相似度评分。候选默认不展示答案，家长可展开查看。
2. 家长选择知识点及目标难度，确认原题已去除隐私信息后生成一题。分类与相似题共用家庭月次数、预算及清理版本；每个孩子同时只保留一个未结束AI请求。每次重新生成都需结束原请求、重新同意发送，并计为新请求。
3. 生成题明确标为“AI生成·待家长审核”，显示模型/提示版本及低置信提醒。答案与解析默认隐藏，可以展开、编辑、重新生成及反馈。当前请求绑定原题学科，不能以改写学科绕过本次复算；已采纳题目仍可通过普通错题编辑流程更正分类。
4. 点击“复算并确认采纳”，服务端对最终编辑内容重新检查。家长明确核对题干、全部标准答案及解析后才保存；录入不发金币/XP，不将AI置信度当作掌握状态。
5. 题目进入现有错题库/复习队列，可和普通错题、拼音词语一起选择生成A4练习卷。列表、详情、编辑、复习与PDF快照保留AI来源标记；PDF继续使用原来的答案和解析显隐开关。

## 数学复算的实际范围

`arithmetic-v1`直接解析**题干本身**，不信任模型另提供的验算式，不使用eval或动态SQL。支持整数、有限小数、分数、四则运算、括号、一元正负号与运算优先级；使用有理数的分子/分母精确运算，`0.1+0.2`及`1/3+1/6`不会因浮点误差误判。

- 接受裸算式和“计算：”“请计算：”“求值：”前缀，识别`×÷−（）`及`=?/？`结尾。
- 数字token最多18字符，算式最多240字符/81个token，递归深度20，约分后的分子/分母绝对值不超过10^60；除零、错误语法或超限返回失败。
- 所有可解析的数值标准答案必须等价；任一答案错误都会阻止采纳，修改后可重新复算。
- 应用题、单位答案、几何、代数、科学计数法和无法直接解析的题意标为“需人工核对”，不宣称验证了题意或解法。语文、英语、开放题及多音字同样要求家长核对。
- 即使数值复算通过，解析仍需人工审核。已保存AI题目的后续编辑也会复算最终数学题干与答案。

规则仅解决其支持范围内的算术一致性。复杂题意校验、真实教材覆盖与模型误判率仍需要评测，不能凭本地测试承诺AI出题正确。

## 持久请求、权限与隐私

原题UUID/内容版本留在应用与服务端校验层；供应商只收到年级、学科、原题文字、知识点、目标难度，不收到UUID、姓名、图片、原题标准答案或作答历史。领取前检查原题归属、内容版本与文字一致性，旧原题不能冒充新版本。输出契约沿用model_version、prompt_version、confidence、raw_output、structured_output和safety_flags；拒答/安全标签会清空普通输出。接口按[OpenAI Structured Outputs官方文档](https://developers.openai.com/api/docs/guides/structured-outputs)检查结构及拒答，提示版本为`similar-question-v1`。

模型只生成建议。数据库负责复算和保存；客户端提供的“已通过”字段不能替代服务端检查。家长最终确认后，**先在加密本机AI草稿中冻结审核内容，再发送保存**。同一AI请求的采纳回执唯一，并发或未知响应只核对原请求；重复保存不新增题目。同一请求改换内容会被拒绝，已删除题目的回执不会重新创建它。

取消屏障与采纳按相同家庭设置/请求锁排序：先取消则迟到采纳失败，先采纳则题库记录保留。采纳仅在开关、策略版本、清理版本、保留期和安全结果仍有效时执行。PIN到期隐藏结果、候选答案及嵌套编辑页；账号变化或本机隐私清理阻止迟到回写。

| 数据 | 生命周期 |
|---|---|
| 本机冻结输入与审核内容 | 加密、按账号/孩子隔离；结束、相关本机清理、孩子删除或账号注销时清除 |
| 临时模型结果 | 沿用1/7/30天、关闭/取消/清理及迟到结果丢弃规则；共享原有Cron |
| 已审核题目与来源 | 成为家长主动保存的题库数据，不随临时AI结果到期删除；按题目或孩子清理规则删除 |
| 来源元数据 | 原题引用/版本、模型/提示版本、置信度、生成摘要、复算结果及最近审核内容版本；不另存永久模型正文 |
| 保存回执 | 保留请求UUID及审核内容摘要以去重；题目删除后引用置空，孩子删除/请求者Auth删除时级联清除 |
| 反馈 | 固定问题类型，无自由文本正文；关联原模型/提示版本，不自动调用模型；请求/孩子删除时清除 |

删除原题不会自动删除家长已另行采纳的独立练习题，原题引用会置空；任何孩子题目永久清理仍会取消该孩子未结束AI结果。导出新增`ai_question_origins`、`ai_question_adoptions`和`ai_feedback`三类，总计33个CSV；保存回执不导出owner_id或config_hash，反馈包含关联模型/提示版本。临时结果清除仍撤销服务端导出副本，已下载文件由用户管理。

## 部署与验收

- 相似题功能由迁移034引入，当前部署需按顺序应用001–036迁移及更新后的`ai-analysis`入口；036增加周报并将导出扩展为34类，不新增Edge函数、供应商密钥或Cron。旧分类请求继续兼容。
- 运行`test:ai`、`test:db`、`check:edge`与Flutter回归。新增10项客户端检查及10组真实PostgreSQL检查，覆盖精确计算、权限、两连接并发保存、快照标记、原请求恢复、PIN/清理隔离、反馈/导出及真实删除工作流。
- 必须选定并评测支持当前JSON Schema的模型，针对分类1500及相似题2500的最大输出token额度重新校准预算预留。示例`reserve_cents=100`不是模型实际报价。
- 上线前继续进行教材/年级/开放题/安全样例评测、原生字体与无障碍、两端弱网和连续家庭试用；真实供应商保留策略仍需确认。
