# 任务完成反馈与怪兽能量

2026-11-05，按PRD6.8补齐任务完成的表现层反馈，以及声音/动画开关。金币、XP、任务状态和成长解锁仍由原有队列及服务端事务决定。

## 用户流程

- 普通任务完成、本次自动复习全部作答并完成后，保存成功才显示完成提示和轻微的小怪兽动作。离线队列写入成功显示“完成记录已保存本机，奖励待同步确认”；保存失败不播放成功反馈。
- 小怪兽动作600毫秒，提示停留1500毫秒，进入/退出各150毫秒；模拟帧回归验证两秒内结束。页面不等待声音/动画完成，不新增强制弹窗。文字状态及待同步记录持续保留在任务页面。
- 冒险大厅昵称下方显示当前怪兽能量；“我的角色与成长”展示完整能量条和待确认数量。能量来自当前孩子、家庭日期的当日任务及尚未终结的积压任务，已完成一项减少一格；过去日期的终结记录不累加进今日展示。放弃/跳过不计作完成，不减少已有金币、XP或已解锁物品。
- 待同步完成记录可先降低表现层能量，并明确标注未确认。同步冲突后的能量跟随当前任务状态重算；它不是新的资产、战斗属性或奖励条件。
- 大厅“更多 → 声音与动画”和成长页右上角均可设置。完成提示音默认关闭，使用短促系统声音并遵循系统声音设置；不绕过静音或系统限制。反馈动画默认开启，系统减少动态效果/辅助导航始终优先，关闭后仍显示静态文字与能量。

## 持久化与生命周期

`DeviceFeedbackPreferences`仅存两项设备偏好，不含账号、孩子、任务或题目数据。该设备上的所有孩子共享偏好。读取失败时效果暂时关闭，可重试；保存期间防止重复切换，保存失败保留原设置并明确提示。

只在本次完成调用成功后触发效果；页面刷新、任务读取、同步重放不触发。页面销毁、仓库切换或应用进入后台后不启动迟到效果。同一页面的同一任务不会重复庆祝，声音接口失败不能使已保存的任务显示为失败。完成按钮关闭默认点击反馈，避免与新增提示音叠加。

## 验证范围

新增客户端检查覆盖家庭日期/孩子/重复记录与终态计数、偏好重新读取/损坏/失败/并发/销毁、两秒内结束、关闭声音和动画、系统减少动态效果、同步及异步音频错误、后台抑制、360px双倍字号、进度条读屏、复习刷新不重放，以及真实SQLite队列提交先于网络回复且钱包不变。

本轮没有修改数据库、奖励规则或原生接收器。完整测试、覆盖率及普通APK见[测试记录](TESTING.md)与[构建记录](ANDROID_BUILD.md)。华为鸿蒙4.2/iPhone上的提示音、系统静音、读屏、偏好重启及真实任务反馈时延仍需设备验收。
