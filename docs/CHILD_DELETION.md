## 使用与保留范围

家庭管理 → 孩子右侧删除 → 预览数量 → 输入“永久删除孩子”。要求家庭管理员、当前会话有效PIN及未变化的范围数量。未知响应保留UUID重试，范围变化要求重新预览。最后一个孩子也可删除，原家庭保留添加孩子、PIN和删除记录入口。

| 数据 | 确认后的处理 |
|---|---|
| 业务数据 | 同事务删除档案、任务/计划、错题/复习/标准答案、OCR来源、钱包/账本、兑换、成长、PDF快照、导出副本和关联审计正文；不可恢复 |
| 本设备缓存与队列 | 清除所有本地账号中匹配孩子UUID的任务/复习、家庭档案和待同步操作，清除内存图片并停止原提醒；保留其他孩子的数据及操作 |
| 云端文件 | 先持久化可信清单，至少等待10分钟，并遵守旧PDF租约及清理任务的等待期，再调用Storage API删除和验证 |
| 删除任务记录 | 失败保留清单并重试；完成时擦除清单及题目/草稿/组卷ID数组，完成记录保留30天 |
| 删除标记 | 只含孩子UUID、家庭UUID和时间，保留至家庭删除，供其他设备清理旧缓存；不含姓名、题目、路径或账号身份 |
| 已下载或分享的副本 | 由用户管理，应用不能远程擦除 |

“业务数据已移除”与“文件清理完成”分别展示。提交成功或HTTP202不代表文件已删除；失败可从家庭删除记录重试同一任务。后台已授权任务可由可信Cron执行，不要求家长一直停留在页面。

上述业务保留期仅指应用主数据库。上线前仍须确定并公开云端备份实际保留期，并在真机验收拍照、相册、系统文件选择器的临时文件生命周期。本地测试不能证明这些外部数据已清除。

## 服务端保证

- 同事务冻结原图/处理图、PDF、已有清理任务路径及两个业务桶内该孩子目录的遗留对象，再删除业务数据。不接受客户端文件路径；发现跨孩子或非支持路径则整个请求回滚。
- 孩子行锁阻止新增外键记录和删除交错；孩子清理锁、请求UUID保证并发重试只有一项任务。先删私有答案，避免RESTRICT外键阻止孩子级联删除。
- 接管旧清理任务并标记superseded、撤销租约；旧worker不能重新领取或完成。新任务沿用旧PDF租约截止加10分钟的等待期。自建worker生命周期变化时必须重新验证该窗口。
- 孩子删除保留兄弟姐妹及家庭共享奖励目录。家庭有未完成文件清理时禁止删除，避免级联移除清单。原delete_child接口已撤权，旧客户端必须升级。
- 沿用permanent-cleanup/executeCleanup，按桶调用Storage remove并逐路径exists验证，SQL完成事务再检查清单及孩子目录下没有Storage对象。不能仅删除Storage索引就认定真实文件清理成功。
- 删除管理RPC及直接读取child范围的清理记录均限定PIN管理员；UUID删除标记允许家庭成员读取，以便孩子模式也能清理本机缓存。

## 重连与本机数据

Drift schema2新增deleted_children，v1升级保留原缓存及队列。持久化标记阻止旧任务快照和新命令写回；家庭缓存过滤已删孩子，复习缓存代际检查拒绝迟到请求。只清理匹配孩子的数据，其他孩子和账号的无关缓存不受影响。

家庭在线刷新会在拉取家庭后读取删除标记；即使家庭结果较旧也会过滤已删孩子。任务同步收到权限拒绝时，再查询删除标记，只有确认删除才执行全设备清理。普通权限/网络错误不会被当作删除。确认当前孩子在另一设备删除后，刷新家庭、关闭旧详情路由并清除通知。

离线设备不能远程即时擦除，该行为依赖实际收到服务端标记。迁移023增加家庭解散后仍可读取的成员撤销通知，schema3增加账号注销标记，参见账号注销说明。
