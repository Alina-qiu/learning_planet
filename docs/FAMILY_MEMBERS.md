# 家庭成员与邀请

2026-11-05：对应PRD第3节的家庭角色、第4.2节家庭设置中的成员及第6.1节家庭隔离。入口为家长模式 → 家庭设置 → 家庭成员与邀请。

## 已实现行为

- 验证当前家庭PIN后联网读取成员列表，标明家庭创建者、管理员、普通家长和当前账号。普通家长只能查看，其他成员邮箱作部分隐藏；管理员可以管理邀请。
- 管理员创建邮箱邀请，有效期7天。对方使用对应邮箱登录后，沿用已有自动加入流程；应用不发送邀请邮件，页面明确提示自行告知。
- 显示待加入和过期邀请，支持撤销及过期后续期7天。重复创建同一有效邀请不会悄悄延长有效期；已加入的账号不会新增邀请。
- 撤销不会移除已经加入的成员。续期、撤销均携带列表中的版本；已接受、已撤销或已续期的旧邀请操作返回状态冲突，要求刷新。
- 邀请变更前将原始请求和固定UUID保存到当前账号的加密SQLite。一次只处理本账号本家庭的一项请求，不在后台自动提交。重启后可核对、重试原请求或停止尚未执行的请求。
- 已完成的请求返回原回执；停止未知请求会记录取消屏障，迟到提交不能执行。停止不能撤回已执行的操作。表单被服务端拒绝后仍可停止并重新填写。
- 页面展示、弹窗确认、写入前后均检查账号、家长授权版本与家庭；PIN失效或账号切换时隐藏邮箱和表单，不采纳迟到响应。仓库额外检查本机清理版本及账号注销标记。
- 管理员可在二次确认后移除普通家长，不能移除自己、创建者或任何管理员；孩子、任务和奖励保留。操作沿用持久请求、核对/重试/停止机制，与邀请操作共用本账号本家庭的单项队列。
- 移除使用成员版本比较，已离开或重新加入后的旧版本不能删除新成员关系；已执行请求重放仅返回旧回执。移除时撤销该成员当前邮箱的旧待加入邀请，避免自动重新加入。
- 被移除账号的应用在前台进入、恢复及每15秒联网核对权限，无孩子的家庭也核对。获知撤销后关闭相关受保护页面，按账号和家庭清理缓存、未同步操作、图片草稿及提醒；其他账号、其他家庭的数据保留。离线或关闭的设备无法即时清理。

## 数据与权限

按顺序应用迁移001–050；邀请管理由 `202611050049_family_invitations_management.sql` 提供，成员移除与权限撤销由 `202611050050_family_member_removal.sql` 提供，均未部署到远程服务。

| 接口/数据 | 用途 |
|---|---|
| `load_family_members` | 当前家庭PIN保护的成员与待加入邀请列表；回执包含当前查看账号和家庭，客户端复核 |
| `resolve_family_invitation` | `invite`、`renew`、`revoke`命令；`submit`、`inspect`、`cancel`处理方式 |
| `family_invitations` | 新增撤销时间及版本；已接受/已撤销记录不占待加入邮箱的唯一索引 |
| `family_invitation_receipts` | 私有请求哈希和结果，不保存邮箱、PIN或命令正文；随账号或家庭删除级联清理 |
| `accept_family_invitations` | 使用Auth账号当前邮箱，排除过期/已撤销邀请；与撤销操作锁定同一家庭行 |
| `resolve_family_member_removal` | 管理员及PIN保护的移除命令，比较成员版本，支持原请求核对与取消屏障 |
| `family_member_removal_receipts` | 私有请求哈希及结果，不保存邮箱或PIN；随账号或家庭删除级联清理 |
| `family_membership_states` / `family_membership_access` | 按账号返回版本化的成员状态、最后撤销版本及相关孩子编号；家庭解散后仍可读取自己的清理通知，账号删除时级联清理 |

邀请创建、续期、撤销和接受均写审计；审计详情仅包含请求编号、版本或计数，不重复写邮箱。旧 `invite_family_parent` 调用保留，内部采用相同权限和锁定流程；旧调用没有客户端请求编号，不能提供新页面的跨重启核对体验，也不再自动延长已有邀请。

成员列表不落盘。待确认的邀请或移除操作存入 `invitation-command:<family_id>`，移除显示用邮箱只留在加密本机请求内，不进入服务端命令或回执。成功联网读取全部家庭后，只清理当前账号已不可访问家庭的待确认请求；离线回退不执行该清理。清理后的迟到回执不能重建请求。

SQLite升级到schema5，新增按账号/家庭的权限状态及待完成通知清理记录。即使设备错过移除、首次联网时已经重新加入，也会依据最后撤销版本清理旧成员关系下的缓存和队列，再加载新数据。图片草稿UUID屏障防止旧上传回调恢复草稿；不将成员移除写入全局“孩子已删除”标记。原生提醒清理失败时保留待办，下次网络读取前先重试，确认只适用于同一版本；其他家庭的提醒范围保留。

服务端移除同时撤销目标账号在该家庭的PIN授权、任务同步租约、配置计时及推送注册/能力。普通客户端不再直接增删改成员表；创建家庭、接受邀请及账号清理走已有受控接口。任务快照与任务命令持有家庭共享锁，与移除串行：先执行的同步完成后再移除，新生成的租约也会被清理；后执行的同步因失去成员权限而被拒绝。客户端同步前读取权限，并丢弃跨权限版本的迟到快照。
