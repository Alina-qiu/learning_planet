# 更改图片或识别结果后的重新校对

日期：2026-11-06，对应PRD ERR-01/ERR-02及用户确认的逐张校对流程。

## 修复的问题

原流程允许从校对页返回后重新裁剪、旋转、增强或执行OCR，但没有清除已有校对草稿。实际复现表明：识别结果已变为新题目，重新打开校对页仍载入旧题干、旧答案和四个已确认字段，导致确认标记与当前图片/识别结果不匹配。

复现使用实际校对页面、真实本机草稿仓库及SQLite，OCR返回值为可控测试数据。失败证据为`tmp/ocr-source-reproduction-stale-fields.log`；此前测试适配的编译及异步等待错误单独保留，不当作业务问题证据。

## 现在的行为

- 当前图片有未提交的校对草稿时，旋转、裁剪、增强或重新识别会先提示。选择“保留校对内容”不处理图片、不执行OCR，也不改写草稿。
- 确认更改处理图后，清除这一张图的旧识别结果、校对文字、答案与字段确认标记，并保存本机。原图和其他图片草稿保留；再次打开时按新图片重新校对。
- 确认重新识别后，只有新识别成功才替换旧结果并清除旧校对草稿。识别失败保留原结果及校对内容，允许继续原校对或重试。
- 新校对页从当前OCR生成文字，标准答案留空，字段确认重新勾选。孩子模式继续允许留空参考答案，并须由家长确认标准答案才能进入奖励复习。
- 弹窗等待及OCR返回后重新检查账号/家长授权；PIN到期不能借旧弹窗清除或重新处理草稿。已进入保存重试的确认配置继续锁定，沿用原请求，不参与本次重置。

修改位于`lib/features/wrong_questions/presentation/question_ocr_screen.dart`。没有修改服务端迁移、奖励规则、上传回执或原生识别引擎。
