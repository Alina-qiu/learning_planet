# 家长家庭概览

2026-11-05，对应PRD第4.2节“家庭概览：多孩子切换、今日完成、待处理事项、周趋势”。家长首页新增“家庭概览与待处理事项”，验证当前家庭PIN后可进入。

## 页面与口径

- 默认查看当前家庭全部孩子，可用孩子筛选切换统计范围；筛选不修改全局选中的孩子，也不切换其他家庭。孩子按创建顺序展示，不按完成率排名。
- 今日完成和近七日趋势按服务端家庭时区、任务`due_date`汇总已生成实例，与现有学习报告一致。批准请假排除，主动跳过或放弃仍在应完成数中；后续补签更新原日期。无任务日显示“无任务”，不解释成完成率0%或100%。合计为完成总数/应完成总数，不平均各孩子百分比。
- 每个孩子单列待审批、待履约、超额金币待确认笔数与金额；分别打开该孩子的兑换记录或账本。查看任务、查看周报也传递明确的孩子和家庭标识，返回概览后重新读取。
- 已到期但仍处于requested/approved的兑换单列为“等待系统取消退款”，不计入可审批/履约数。只读概览不执行过期、退款、任务生成或奖励结算；进入现有商城流程后依原规则核对。
- 数据来自已同步记录，尚未同步的本机打卡不混入云端汇总。网络失败显示重试入口，不用零统计替代失败；支持下拉刷新。普通字号与双倍字号均使用可滚动页面和换行按钮。

## 后端与权限

迁移`202611050052_family_overview.sql`提供`family_overview(target_family_id)`，按顺序部署001–052后使用。接口要求当前会话的家庭PIN，并沿用活跃账号、家庭成员和家庭删除状态检查；普通家长授权后可读，其他家庭、无PIN、匿名账号及已移除成员被拒绝。

一次请求返回家庭日期/时区及每个孩子固定七行统计和待办计数，不逐条下载任务、兑换历史、账本、题干或原因。新增孩子家庭索引、未终态兑换及待确认金币部分索引；测试包含1000条已履约历史，仍只返回摘要。查询标记为stable，已在数据库只读事务中实际执行，未触发业务写入。

客户端检查返回家庭、孩子去重、连续七个日期、非负整数及完成数不超应完成数。数据仅在页面内存中使用，不新增本机数据库结构或缓存；PIN/授权版本、登录账号或退出状态改变会隐藏或重新读取数据，过期请求不恢复旧页面。真实SDK适配器另检查返回前账号未变化。
