# 家长调账明细与账本显示

更新：2026-11-06。对应 PRD 6.4、AC-06 的操作者/时间/原因，以及第13节“查看账本来源”。原来服务端已保存调账审计，App只显示金额和来源代码；本次接通原始说明的只读入口。

## 使用方式

账本将任务、计划、连续学习、学习表现、家长调账、超额确认、兑换冻结/兑现/退款显示为中文。可用金币和冻结变化分别显示正负值，XP不显示无关的冻结金额。奖励开放时间、兑换期限、账本时间和离线读取时间按服务端返回的家庭时区显示，去掉原始ISO时间戳；旧缓存没有时区时明确标为本机时间。未知来源保留为“其他记录”，不删除记录或推测其来源。

家长联网验证PIN后，可点击“家长调账”账本行查看该次调账的金币/XP、原操作人、操作时间与原因。退出/过期家长授权后隐藏说明，离线账本保留金额并提示联网验证。明细不写入持久缓存，读取和重试不调用交易接口。历史操作说明若已被隐私删除清除，显示不可用，不借用其他操作的说明。

## 后端与权限

迁移 `202611060066_wallet_adjustment_details.sql` 增加 `wallet_adjustment_details(child, ledger)`，只接受该孩子的 `parent_adjustment` 账本，检查当前账号、家庭成员和当前会话PIN。通过原记录的来源编号、孩子、家庭、审计动作严格关联 `wallet.adjust`；没有新增调账或余额写入。调用不返回幂等键、原命令编号或任意审计详情，并支持只读事务。

身份显示遵循家庭成员页面的既有规则：管理员可核对账号，其他家长看到其他操作者的脱敏邮箱，自己的账号标为“我”。已离开家庭的操作者单独标记；注销/删除按既有清理规则使审计内容不可用。客户端检查响应归属、账本金额和审计金额一致性；切换账号/角色、PIN续期版本变化、移除成员、删除孩子或仓库销毁后，迟到响应丢弃。

同一迁移让四类 `economy_page` 返回 `family_timezone`，不改变首批上限、排序、游标和现有交易规则。客户端拒绝混合不同家庭日期或时区的四页结果；新缓存保存时区，旧缓存仍可只读查看。
