# 模板与长期计划的离线查看

2026-11-05，对应PRD ACC-03最近数据离线查看及孩子任务中心的查看计划。原只读入口已有，但每次必须联网下载模板，再逐个查询长期计划进度；现提供分页汇总、完整加密缓存和明确的离线状态。

## 页面行为

- 入口仍为任务页的日程按钮，页面标题缩短为“计划与提醒”。孩子可查看模板规则、计划奖励、已批准请假和完成进度；写操作仍需家长PIN。
- 联网完整读取后保存当前账号/孩子的模板与计划。网络中断时显示上次完整记录和服务端读取起始时间，按本机时区展示时间并明确标注；进度、请假及奖励可能已变化，不把缓存当作当前云端状态。
- 离线时隐藏配置、编辑、启停、请假和结算操作，保留查看与刷新；没有缓存、权限被拒绝或修改结果未确认时显示可重试错误。空列表也可用顶部刷新按钮重新读取。
- 列表按可见行构建，1000条模板不会同时构建1000张卡片；按创建时间及ID倒序展示，不截断旧模板。中文普通/双倍字号已复核，周期名称不再显示`daily`等内部值。
- 长期计划完成率仍遵循原算法：整个计划的应完成日期含未来日期，排除已批准请假；未生成日期也计入分母。离线打卡不会直接改写缓存中的云端计划进度或发放阶段/终奖。

## 数据与范围

新增迁移`202611050053_schedule_snapshots.sql`，需按顺序部署001–053。`task_schedule_page(child,after_created_at,after_id,page_size)`使用创建时间/ID游标，每页最多200条，客户端每页100条。每页包含计划进度、阶段奖励、终奖档位和请假日期，无逐计划HTTP往返；不返回请假原因或任务正文。接口只读，实际只读事务测试通过，不生成任务或结算奖励。

允许具有孩子访问权限的家庭成员读取，不要求家长PIN；匿名、其他家庭、已删除孩子或被移除成员不能读取。每次分页重新检查权限。客户端核对孩子、家庭、家庭日期、重复模板和重复游标；中途失败不把部分结果写入缓存。

使用现有schema5加密数据库的`schedules:<child_id>`和`schedule-version:<child_id>`键，无SQLite结构升级。最新发起的读取优先；模板保存、启停、请假和结算四个仓库入口在请求前后更新版本并移除旧缓存，回执丢失后需联网核对。旧读取不能覆盖之后的修改或新读取。

缓存按账号和孩子隔离，加入孩子删除、成员撤销及账号注销的既有清理；账号变化、清理版本变化和已知权限撤销后，迟到响应不能重新保存数据。网络失败才可回退，业务/结构错误不能伪装成离线成功，明确的42501会删除缓存。数据仅用于查看，不新增写操作队列或改变任务/账本幂等协议。

## 验证与限制

- 新增12项Flutter检查：游标分页和请求数量、真实文件数据库关闭重开、多账号/孩子隔离、第二页失败保留完整旧缓存、权限与格式拒绝、账号/清理后的迟到响应、新旧读取与修改交错、范围删除、四类写操作回执丢失、并发写入/退出、离线界面与双倍字号、1000条可见行构建及PIN变化后的编辑阻止。
- 新增4组数据库检查，完整305组通过，覆盖1006条模板和相同时间戳、跨页新增/删除、计划进度与未来日期/请假、读权限和参数界限、空孩子及只读执行。数据库没有PostgREST服务，真实SDK传输另以模拟HTTP验证。
- 模块24项回归及1项截图检查通过。实际中文字体截图为`tmp/schedules-offline-1x.png`和`tmp/schedules-offline-2x.png`。首次测试夹具有条件表达式拼写和旧清理方法名错误，修正后通过，编译失败记录保留于`tmp/schedule-snapshots-fixture-compile-failure.log`。
- 分页期间的新模板在下次刷新出现；不同页可反映各自读取时的最新进度，不声称整份列表是跨请求数据库快照。缓存时间取首次分页读取时间。
- 离线设备不能立即得知另一设备的修改或撤销；首次打开和明确拒绝访问不降级为缓存。尚未部署到Supabase或在华为鸿蒙4.2/iPhone实测，首屏性能仍需真实后端和设备测量。
