# 复习队列稍后提醒

对应 PRD ERR-06。错题本和拼音词库上方的今日复习队列提供“稍后提醒”：约15、30、60分钟后提醒一次，可改期或取消。采用服务端时间，向上对齐到下一整分钟，界面显示家庭时区中的预约时点。预约不改变复测日期、题目快照、任务状态、有效时长、金币或XP，仍可随时进入复习。

## 规则与范围

- 每个自动复习任务只保留一个预约，整条复习队列共用；不将单题移出已经生成的题目集合。孩子模式可操作，不要求家长PIN；仍必须是有权访问该孩子的登录家庭成员。
- 仅为家庭当天未结束的自动复习任务预约。非复习任务、已完成/放弃/跳过/过期任务、跨次日时点、家长关闭提醒及安静时段内的请求均被拒绝。
- 这是用户主动设置的额外预约，普通任务的默认三个时点保持不变。同一时点仍合并为一条通知，锁屏正文不包含孩子、题目或答案。
- 当前设备需启用孩子任务提醒并取得系统通知权限；处于家长提醒模式时引导先切换模式，不自动替换家长的选择。
- 设置需要联网；离线仍可查看缓存及进行已有复习。已经排程的预约可由系统触发，受原有60条上限、系统节电与[本地通知边界](LOCAL_NOTIFICATIONS.md)约束。
- Android实际显示前复查安静时段和15分钟有效期。iOS后台显示由系统控制，延迟跨静默边界仍未解决；iOS代码及真机未在本机验证。

## 并发、失败与清理

迁移048增加私有`review_reminder_requests`，以任务ID为主键。`set_review_reminder`与任务完成共用任务行锁，以修订号阻止旧设备覆盖新设置；相同命令与载荷返回原结果，不重新计算时间或重复写审计。不同载荷复用命令标识被拒绝，旧请求不能撤销后来的取消。

界面在网络结果不明确时保留原命令供重试，并允许重新核对服务端状态。预约保存与本机排程分别显示结果；本机排程失败只重试同步，不重新创建预约。完成或放弃任务时清除未来预约，终态任务不会再生成提醒；离线未同步终态沿用现有任务ID过滤。

变更前后递增按账号/孩子保存的提醒缓存版本并移除旧缓存，期间暂停加载。迟到响应不能写回旧计划，网络失败不能使用变更前缓存恢复已经取消的提醒。预约变更先清理当前设备待发计划；其他设备在下次同步后更新，不能声称离线的另一台设备会立即取消。

预约记录随任务/孩子删除级联清理，审计沿用现有任务归属清理。家长授权导出新增`review_reminders.csv`，包含任务ID、修订号、延迟分钟数、预约及请求时间，排除内部命令UUID；导出共39类CSV。

- 客户端新增8项测试：严格解析、真实SDK请求字段与账号/隐私变化、真实Drift缓存版本及重启后旧计划隔离、响应丢失重试、本机同步重试、权限/家庭开关、360px双倍字号、复习页入口。界面截图使用合成数据和本地中文字体检查。
