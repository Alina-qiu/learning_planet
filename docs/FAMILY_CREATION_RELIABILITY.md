# 家庭与孩子创建请求恢复

2026-11-04：依据PRD 5.1首次使用、6.1账号/家庭/同步以及“所有写入需幂等并留审计记录”，补齐创建家庭和添加孩子在网络结果未知时的恢复路径。

## 使用行为

首次填写家庭名称、孩子昵称、年级、教材标签和头像后，点击提交会先将请求保存到本机加密数据库，再访问服务器。请求编号、计划创建的家庭/孩子编号与表单内容一同固定。正在提交和结果未知时不会出现可继续修改的第二份创建表单。

未知结果会显示“待确认的创建请求”。退出页面或重启后，再打开相同入口即可恢复。“核对并重试”先读取服务器回执；已成功则显示原有档案，服务器尚无回执时才用同一请求和同一内容继续提交。新版本不会在后台自动创建家庭或孩子。

“修改填写内容”先说明处理方式并联网核对：

- 原请求尚未成功时，服务器记下取消标记，再允许修改原表单并产生新的请求编号。迟到的原请求会被取消标记拦截。
- 原请求已经成功时，保留已创建档案并显示查看入口，不执行删除、不再开放第二份创建表单。
- 取消响应丢失时仍保留原请求，后续核对可恢复取消结果。

成功回执保留到家庭列表能够显示对应编号的孩子后再清除，列表刷新失败可以继续查看同一回执。若重启时正常家庭加载已显示创建结果，应用会直接进入已有家庭，不会重建。尚未处理的本机请求继续受账号/孩子清理规则管理。

添加孩子时，页面随家长PIN到期隐藏待确认内容；重新验证后恢复。服务器首次执行添加仍检查当前账号、家庭管理员身份及有效会话PIN。PIN不进入请求载荷；退出登录、切换账号及注销不能让旧响应写到另一个账号。

## 持久化与服务器约束

客户端复用Drift schema4中的账号缓存，使用`creation:family`和`creation:child:<familyId>`保存每个入口的一条未处理请求。昵称、教材等内容随整库加密；读写均校验当前账号。预先固定孩子UUID，使删除标记可以找到并清理尚未收到创建响应的本机内容。

迁移031新增私有`family_creation_receipts`与`resolve_family_creation`：

| 操作 | 行为 |
|---|---|
| inspect | 只核对本人请求；无回执时返回unknown，不创建档案或取消标记 |
| submit | 同一请求编号和内容重放返回原结果；首次成功在同一事务创建家庭/成员、孩子、钱包、回执与审计记录 |
| cancel | 尚未成功时写入取消标记；已成功时返回原档案结果，不删除业务数据 |

服务器按请求编号加事务锁，绑定JSONB规范化内容的SHA-256摘要。相同编号但内容不同会被拒绝；两个连接同时提交只有一份业务记录和审计，不增加金币或XP。取消与提交使用同一个锁，谁先完成决定统一结果。

回执不保留昵称、教材标签或完整表单，也不向authenticated/service_role开放表读取。核对接口校验请求所属账号，只返回编号和状态；新增孩子执行需要管理员/PIN，单纯读取已有本人回执不延长PIN授权。

孩子或家庭删除后，同一请求返回unavailable，不会再次创建；孩子删除标记也拦截用新请求编号复用被删除的孩子UUID。回执的UUID及摘要屏障保留至请求账号被Auth删除，避免因家庭级级联删除而失去防重放能力。已申请注销的账号即使仍持有旧JWT，也不能核对、创建或取消请求。

客户端收到unavailable后清除该账号的本机请求正文并隐藏预览。孩子删除、账号注销及迟到响应继续使用已有本机清理屏障，不能恢复已清理内容。

## 验证与部署

新增11项客户端检查和6组数据库检查。全量214项Flutter测试、168组真实PostgreSQL检查通过，Dart静态分析无问题，119个Dart文件格式及git diff检查通过。覆盖SQLite重启、不可变内容、真实Supabase SDK请求重放、账号切换、删除竞态、取消竞争、非管理员/PIN限制、320逻辑像素与放大字体的表单提交及恢复。

测试数据库为独立临时PostgreSQL，Auth/Storage采用模拟表；客户端HTTP由测试注入。Flutter使用`--no-pub --no-test-assets`，不代表原生资源构建、真实网络或双设备验收。

发布时先部署`202611040031_durable_family_creation.sql`，再发布依赖新RPC的客户端。旧版建家/新增孩子RPC保留兼容，旧客户端不会自动获得本机持久请求与取消屏障；需要升级客户端。不同请求编号代表不同创建意图，不按昵称合并孩子，也不把两个设备各自新建的不同请求视为同一个人。

真机还需验证：请求发出后断网/杀进程、长时间超时与迟到响应、取消时切换网络、PIN到期、另一个设备删除档案、退出并切换账号，以及首次创建后读取家庭列表失败。当前未部署云端、未创建Git提交；完整APP仍待AI/隐私设置、原生联调及发布验收，见[开发进度](PROGRESS.md)。
