## 入口

首页“错题本与拼音复习”，或任务管理右上角“错题与拼音复习”。每日自动任务标识为自动错题/拼音复习，并直接进入逐题页面，不走普通任务的一键完成/补签流程。

家长先在首页进入家长模式、验证 PIN。错题本支持手工录入题目、学科、知识点、一至五个标准答案和解析，编辑或归档。归档保留历史快照，不删除旧复习记录。编辑重置该题当前复习阶段并更新内容版本；已生成的旧题仍按原快照判定，不影响新版本掌握情况。

拼音词库支持词语、语境/例句与家长确认的标准读音。本地词典可提供候选及多音字备选，保存必须显式确认；修改词语、语境或读音会撤销确认。CSV/TSV生词库导入、错词转入与三种纸面出题模式详见[拼音词库与练习卷](PINYIN_WORD_BANK.md)。

## 每日生成与快照

以家庭时区筛选 `review_due_at < 次日00:00`、未掌握、未归档且已有标准答案的题目。按家庭到期日期升序、错误次数倒序、上次作答把握升序（未知最后）、ID升序排序，每个孩子每天最多十题、只一条自动复习任务，无题不生成。已生成任务保留原顺序。

任务生成时即冻结题目集合、题目文本、知识点、语境、内容版本和私有答案快照；比“开始后冻结”更严格。当日后来新增、修改、超量的题目进入积压，不扩充已生成集合。重新运行生成函数不会改已有题目或奖励。

独立复习维护函数在家庭当天00:05后幂等检查，Cron每分钟调用，以支持不同家庭时区及漏跑补偿。任务读取/离线恢复快照和复习概览也执行同一生成RPC。尚未真实运行线上Cron。

## 作答、判定与发奖

开始/继续后填写答案，并选择“不太确定 / 有点把握 / 很有把握”；暂停时不能提交。把握程度用于后续排序，不改变判定与奖励。服务端匹配冻结的可接受标准答案，拒绝任意客户端 `result=true` 或掌握状态写入。标准答案/解析在该题首次提交后才返回，未作答时不会随接口泄漏。

每题第一次提交产生结果和排期；相同答案重试只返回既有结果，不再次增加复习次数，不能拿到解析后修改已判定答案。新任务提交最后一题时一并完成和结算；失败会回滚本次判题/排期/奖励。返回失败时可刷新恢复服务端已有记录，回执丢失后重试不重复发奖。

普通错题采用NFC、大小写、首尾/连续空白归一化后的精确匹配，不提供表达式求值或开放问答的AI评分；家长可配置多种可接受表述。拼音采用服务端统一规则：

- `yín háng` 与 `yin2 hang2`；数字格式可连续输入，符号格式需音节空格分隔。
- `ü`、`v`、`u:`等价，但不把 `u` 与 `ü`混为一谈。
- 大小写和常见分隔符归一化；轻声使用5、0或不标调。
- 声调必须匹配，`hǎo`不接受`hao2`；数字与符号声调矛盾或非法输入提示校正。

迁移061后新生成的任务按阶段结算：订正正确15金币/15XP，7天复测正确25/20，30天掌握40/30；1、3天练习及答错不另发阶段奖励，同题同一内容版本每阶段只奖励一次。迁移前已生成任务保留金币=正确题数×5、XP=作答题数×3+正确题数×2的原约定，历史账本不改写。全部提交并完成后统一结算，使用既有事务和任务ID幂等账本键；普通家长补签不能绕过自动复习逐题作答。软上限与并发等规则见[阶段奖励](REVIEW_MILESTONE_REWARDS.md)。

## 复习阶段

2026-11-05用户已确认：采用“完成1/3/7/30天复测后掌握”，沿用现有实现；PRD5.4中“连续两次复测正确即掌握”的表述不作为本项目最终规则。

答对后依次预约1、3、7、30个家庭日后的复习，完成30天那一轮并再次答对才记为掌握。任一阶段答错则回退到起始阶段、次日复习，并增加错误次数。日期由服务端家庭时区计算，不依赖设备时区。

旧快照作答若与当前错题内容版本不同，仍判定旧题并计入本任务结果，但不推进已编辑新题的阶段、错误次数或掌握状态。规则2的新任务还冻结阶段及应复习时间；与当前排期不符或当前题目未到期、已掌握/归档/删除时，不推进阶段或新增阶段奖励，防止积压快照提前完成未来复测。

## 缓存与当前限制

复习列表、概览、题目与已提交结果按账号缓存；已知权限拒绝不使用旧缓存兜底。家长编辑接口返回的私有标准答案不额外持久化。迁移029补齐复习操作持久队列，支持离线开始、暂停、继续、作答与完成，显示本机待确认答案，联网后服务端判题/排期/结算。不会展示未经确认的正确/错误或发奖；冲突与清理边界见[离线任务](OFFLINE_TASKS.md)。

后续已补齐设备端OCR、私有图片和错题详情/搜索/批量管理，详见 [OCR与错题管理](OCR_MANAGEMENT.md)。PDF、词库导入、三种纸面拼音模式、图片草稿离线恢复/上传和AI建议已有实现；每日拼音仍为看词写拼音，听音/语音评测未实现。手写和公式OCR质量不保证，必须人工校对。

旧数据库错题没有标准答案时，需家长补齐后才能进入自动生成。迁移011保留旧已完成任务和奖励，将无答案快照的旧未完成自动任务记为跳过并写审计，不编造历史答案或撤销已发奖励；当日唯一任务约束仍保留，后续日期再生成。
