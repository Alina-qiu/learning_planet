# AI 分类建议与隐私控制

对应 PRD 7.1 的 V1.1 题目结构化、7.2 输出约束及隐私要求。迁移032、客户端和 Edge 代码已有本地验证；默认关闭，尚未部署、配置真实供应商或完成真实教材及家庭试用。没有实际发送儿童数据。

## 本次范围

- 家庭管理 → AI 与隐私：启用开关、每月请求上限、预估预算和分析正文保留期。管理员可启用及调整参数，所有已通过 PIN 的家长均可关闭。
- 手工录题或 OCR 校对 → AI 分类建议：仅发送当前校对文字、学科和服务端孩子年级。请求不含图片、身份资料、答案、历史记录或内部 UUID。
- 分类接口返回知识点、参考难度、候选错因及置信度。家长逐项确认后，将知识点和候选错因填入当前草稿，再手动保存；分类接口中的参考难度仍只供审核。
- ERR-04的六类人工错误原因标签由迁移035单独保存。当前`question-structure-v1`候选错因仍写入可编辑备注，不自动改动人工标签；书写、记忆等需要结合实际作答由家长选择，不能仅凭原题推断孩子的错误。
- 迁移034及同一网关另增[相似题生成与规则复算](SIMILAR_QUESTIONS.md)：来源版本绑定、答案显隐、编辑审核、反馈及持久采纳。迁移036增加[AI学习周报与逐条依据/反馈](AI_WEEKLY_REPORTS.md)；三种用途共用额度、保留和清理。AI不直接发奖或修改掌握状态，拼音继续使用本地读音候选。

## 请求与额度

客户端在现有加密数据库中按账号、孩子保存请求 UUID、冻结输入和清理版本。每个孩子同时保留一个待核对请求。恢复页面只查询原请求，不会自动发送；输入变更后不能采纳旧题结果。

Edge 使用 Auth 验证传入 bearer，再读取该已验证 JWT 的登录会话编号。服务端检查账号、家庭、会话 PIN、孩子清理版本、家庭开关及网关配置。客户端无法调用 claim/finish，也无法直接读取私有表或 claim token。

家庭设置锁与请求锁保证同一请求只领取一次；摘要绑定原输入，重放只返回状态。领取同时占用月次数和预估预算，额度按 UTC 自然月计算。失败、超时、进程终止或保存结果失败均不自动退款或再调用模型。长时间无结果时，家长可明确结束本次请求，再决定是否新建请求。

每次费用占用来自私有网关配置 `reserve_cents`。它是部署人员按模型、输入上限及输出上限校准的预估上限，并非供应商实际账单或支付限额。数据库能严格限制占用总额与次数，但供应商真实费用仍取决于模型价格、汇率和账单政策；上线前必须校准并配置供应商侧预算控制。初始数值不代表当前模型报价。

取消在服务端建立屏障，阻止未开始的同编号请求；已发往供应商的请求无法撤回。已领取请求在关闭设置、永久清理、取消或账号注销后，迟到输出会被丢弃。新设置采用版本比较，避免两台设备静默覆盖。

## 模型边界

业务界面与 RPC 只依赖统一结果：`model_version`、`prompt_version`、`confidence`、`raw_output`、`structured_output`、`safety_flags`。首个适配器为 OpenAI Responses API；替换供应商时只扩展网关适配器、配置校验及对应测试，不改钱包或复习逻辑。

适配器固定服务地址、禁止工具调用、发送 `store:false` 和严格 JSON Schema，最多1500输出 token、20秒超时，并限制响应字节数。服务端再次校验字段、长度、枚举和置信度；拒答、不完整或无效结果不会被当成正常建议。敏感/高风险标签会清空普通建议及原始模型正文，客户端提示家长核对或寻求可信任成年人帮助。低于80%的置信度明确标注，但所有建议都必须确认；模型自报置信度不等于经校准的正确率。

结构化输出协议依据 [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。`store:false` 用于关闭响应应用状态存储，并不等于零数据保留；供应商仍可能保留安全审查日志，见 [OpenAI 数据控制](https://developers.openai.com/api/docs/guides/your-data)。应用内保留期限只约束本服务，不冒充供应商删除能力。

## 保留、导出与删除

| 数据 | 位置与期限 |
|---|---|
| 待核对输入 | 本机加密数据库；明确结束、采纳、相关永久清理、孩子删除或账号数据清理时移除；不缓存模型响应 |
| 输入摘要、UUID、状态、模型/提示版本及预算占用 | 私有 PostgreSQL 回执；不保存原题输入；孩子删除或请求者注销时删除，家庭汇总额度独立保留到家庭删除 |
| 原始模型文本和结构化建议 | 可选1/7/30天；读取时强制过期，Cron每分钟物理清除；关闭、结束或采纳时提前清除 |
| 导出临时副本 | 新增 `ai_analysis` 类别，排除输入摘要与 claim token；正文清除、缩短期限或请求删除时撤销相关服务端导出快照 |
| 用户已保存的 ZIP / 已采纳的题目字段 | ZIP归用户管理；已采纳字段成为普通题目内容，按题目清理流程处理 |

题目分析只关联孩子，不能可靠判断它源自哪一道已保存错题。因此任何该孩子的永久清理入队时，保守清除该孩子的所有分析正文并递增清理版本；尚未发送的旧草稿也无法再领取模型调用。客户端相应清除该孩子的 AI 输入草稿，其他孩子不受影响。账号注销同时删除该家长在他人家庭中的 AI 请求，并保留共享孩子档案。

## 部署条件

1. 按序应用迁移001–036，确认 RLS/RPC 权限及 `learning-planet-ai-retention` Cron；034扩展相似题，036扩展周报，分类请求保持兼容。
2. 仅在 Edge secrets 配置 `OPENAI_API_KEY`，勿加入 Flutter 的 `dart-define` 或客户端 `.env`。部署 `ai-analysis`；它在入口自行验证 Auth，`verify_jwt=false` 不代表匿名可用。
3. 在受控运维 SQL 中配置 `ai_gateway_config` 的供应商、经过实际教材评测的固定模型版本和校准后的 `reserve_cents`。模型默认空值、网关默认关闭，不推荐或写死未验证型号。
4. 验证模型严格结构化输出支持、访问地区和账户条件、供应商数据保留、超时、成本及错误日志脱敏，再由部署人员启用网关。家庭设置仍默认关闭，需要管理员另行启用。
5. 按项目原计划完成两周核心闭环家庭试用，再开放 AI 增强。验证 Android/iOS 的退出、杀进程、PIN 到期、两端关闭、弱网重复点击、正文过期及后台清理。

操作 SQL 示例仅供审核，不能直接复制占位值上线：

```sql
-- 通过部署人员的可信数据库连接执行；此表不向应用角色授权。
update public.ai_gateway_config
set enabled = false, model = 'REPLACE_WITH_VALIDATED_PINNED_MODEL', reserve_cents = 100;
-- 校准和验收完成后才单独启用，示例100分不是实际模型报价。
```
