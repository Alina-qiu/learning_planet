## 统计口径

| 指标 | 计算方式 |
|---|---|
| 应完成/已完成 | 按due_date选取已生成任务实例，剔除plan_leaves中已批准请假；主动跳过仍在分母。未生成的模板计划不虚构为历史实例。 |
| 有效时长 | 所选日期任务的accumulated_seconds之和，包含未完成任务已保存片段；不估算运行中片段或把暂停计入。跨日任务按应完成日期归属。 |
| 每日趋势 | 周报固定连续7天，月报覆盖自然月开始至月末（本月截止今天）；空白天保留零计数。总体完成率用总数相除，不平均每日百分比。月报的逐日明细默认折叠，可展开查看。 |
| 实际完成记录 | 按completed_at所属家庭日期列出，允许包含此前到期的补签任务；最多显示最近200条，返回实际总条数并提示截断。汇总不受200条限制。 |
| 复测正确率 | 期间answered_at落在日期范围的已判分题目，正确数/已作答数；零样本返回null。 |
| 当前到期题 | 截至家庭今天未掌握、未归档、未进入删除流程、review_due_at早于明天零点的题目，包含积压。查看历史报告时也明确标为“截至今天”。 |
| 金币收入 | 期间正向coin账本，排除兑换退款；包含正向人工调账。待确认超限奖励在批准入账后体现。 |
| 消耗与其他扣减 | 兑换履约redemption_spend的冻结扣减计为消费；其他负向可用金币单列。冻结不当作消费，退款不当作收入。 |
| XP | 期间XP追加账本之和。 |

任务完成率随后续补签变化，累计时长也随同步更新，报告不是不可变历史快照。所有金额和复测时间使用当地零点对应的UTC闭开区间，支持夏令时23/25小时日。建议由“有到期题/无任务/有未完成任务/已完成”确定规则生成，并显示统计依据；未接入AI模型，不宣称AI报告能力。

## 自然月与五维成长

`month`模式的锚点只选择月份。例如传入2024-02-15会返回2024-02-01至2024-02-29，传入当前月任意有效日期则返回月初至家庭今天。上/下月按日历月跳转，跨年和闰年不按固定30天计算；仍拒绝未来锚点。六个月趋势以所选月结束，最早只到2000-01；无记录的月份保留零值。

PRD未规定评分公式。本实现采用版本`activity-v1`的可核对活动指标，不产生能力分、人格评价、排名、金币或XP：

| 维度 | 数值与单位 | 来源 |
|---|---|---|
| 学习 | 完成项数 | `growth_category=learning`的已完成任务 |
| 坚持 | 完成天数 | 所有已完成任务的家庭本地完成日期去重 |
| 专注 | 累计计时，秒/分钟 | 该月已完成任务保存的`accumulated_seconds`之和 |
| 探索 | 完成项数 | `growth_category=exploration`的已完成任务 |
| 责任 | 完成项数 | `growth_category=responsibility`的已完成任务 |

五项均按**实际完成日期**归入月份，包含家长补签；这不等于孩子自主开始率。专注指标可能包含跨日积累的计时片段，不是实时注意力测量，也不按分钟拆分到原发生日期。未完成任务的片段不计入这项成长指标，但仍计入上方按应完成日期汇总的任务有效时长；两个口径分别标注。

任务配置新增“成长统计分类”，可选学习、探索、责任或未分类。旧普通任务与旧模板保留未分类，不根据任务标题猜测；自动错题复习可确定属于学习，迁移时据`source_type`回填。新任务生成时复制模板分类；改模板只影响后续生成实例，已有任务保持原分类。旧客户端编辑时缺少该字段会保留数据库现值，包含等待并发模板锁的情况。长期计划仍遵守原有规则不可变约束。

未分类任务照常贡献完成天数和已完成任务计时，另外显示未分类完成数。每个指标的柱高只在自身显示的月份内缩放，点击可看全部月份的准确数值；不同单位不画共同能力雷达图。当前月明确提示“截至今天”，不能直接把部分月总量与完整月作优劣判断。

## 学科与知识点分布

- 新增题目：按该月`created_at`统计当前题目，使用当前学科与知识点，包含已归档题目。家长随后修改标签会更新历史录入分布。
- 复测：按`answered_at`统计已判分作答，使用任务开始时保存的学科/知识点快照。重复复测分别计数；零样本正确率为“暂无数据”，没有标签或旧快照无学科时明确标注。
- 知识点仍使用现有自由文本字段，多个标签写在同一字段时作为该标签组合统计，不擅自拆词。
- 删除中及已删除的源题不进入分类分布，已脱敏复测仍可保留在整体正确率统计中，所以分布次数可能小于复测总数。清理完成后不通过当前题目联表恢复旧标签。
- 学科及知识点分组完整返回，不受活动明细最近200条的展示限制；统计不返回题干、答案或图片URL。

## 实现与权限

- 迁移019新增只读`learning_report`，033扩展`month`，并新增任务分类快照、录入/作答查询索引和私有月度聚合函数；`day/week`行为保留。
- SECURITY DEFINER设置空search_path，通过require_parent_authorization校验家庭成员、登录会话、PIN过期时间；匿名或其他家庭不能调用。有效PIN的管理员和普通家长均可读。
- 报告不返回错题题干、标准答案和图片URL。客户端按childId/familyId/period/endDate区分请求；授权失效隐藏报表，账号变化作废provider及详情路由，不持久化报告。
- 服务端聚合完整数据，避免客户端列表分页造成总数遗漏；页面提供可读错误与重试，不用虚构的零值代替网络错误。
