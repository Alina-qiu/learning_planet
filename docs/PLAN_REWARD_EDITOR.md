# 长期计划奖励配置表单

更新：2026-11-05，落实 PRD 6.3 的阶段奖励及最高档终奖配置。沿用已有计划、请假分母、阶段结算和终奖数据库规则，本次无单独数据库迁移。

新建长期计划时，阶段奖励可逐项添加、移除并填写完成次数、金币、XP；更高终奖档位逐项填写完成率、金币、XP。页面说明阶段各结算一次，终奖只取达到的最高档，不与基础终奖或其他档位叠加。创建后奖励规则继续锁定。

次数须为正整数，金额须为非负整数；阶段次数不能重复。终奖完成率须为 1–100 的整数、高于当前基础完成率，档位之间不能重复。修改基础完成率后提交时重新校验，不使用打开表单时的旧值。移除前项不会把后一项输入移到错误的控制器。

同时修复隐藏字段阻止保存：关闭长期计划或改为单次任务后，不再校验/提交隐藏的阶段和终奖字段；离开自定义日期规则后，不再解析隐藏日期。切回长期计划保留尚未提交的草稿。服务端仍独立校验最终 JSON 配置。双倍字号时金币/XP 改为单列，重复规则下拉框也已修复溢出。

新增 8 项真实表单测试，覆盖序列化合同、删除保值、无效/重复次数、动态完成率校验、隐藏字段、重复规则切换及 360px 双倍字号。与原排程组件共 11 项专项通过；合并后的全量结果见 [测试说明](TESTING.md)。普通/双倍字号的阶段和终奖中文截图已复核，保存在 `tmp/plan-reward-{stage,tier}-{1,2}x.png`。
