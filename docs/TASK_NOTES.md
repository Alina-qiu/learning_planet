# 任务补充说明

2026-11-05，补齐PRD第4.1节任务中心的“补充说明”。

## 使用方式

任务列表每行提供“补充说明”入口，已完成、放弃和自动复习任务也可进入。孩子模式及家庭成员都可查看和编辑，不要求家长PIN。每个任务保留一份当前共享说明，最多500个Unicode码点，可记录书目、学习困难等；清空后共享即移除正文。共享说明以服务端最后接受的保存为准，不提供历史版本编辑或评论串。

输入立即写入本机草稿。只有点击“共享说明”才向服务器发送；断网可编辑草稿，恢复网络或打开页面不会自动发布。页面展示最近同步内容及更新时间，可主动刷新。草稿、共享缓存和待核对的原请求按账号保存在现有加密SQLite中；不增加SQLite表或改变schema5。

结果不确定时，原UUID和正文锁定，仍可查看和复制。用户可核对、重试原保存或停止未执行的保存。取消要得到服务端确认后才能再次编辑；已执行的保存不会被取消撤回。核对旧回执时如果家人已经更新说明，页面显示最新共享内容并提示原保存已完成。

## 数据与接口

迁移`202611050054_task_notes.sql`新增`task_notes`，通过任务外键关联，使用服务端版本和更新时间。说明独立于`task_instances`：不改状态、计时、同步版本、金币或XP，也不向任务打卡队列追加指令。

- `task_note(task_id)`：家庭范围检查后读取当前正文、版本、时间和任务/孩子/家庭归属。尚无说明时返回空正文和版本0。
- `resolve_task_note(task_id, request_id, note_text, operation)`：支持`submit`、`inspect`、`cancel`。账号有效性及当前成员权限每次重新检查；私有回执绑定账号、任务和正文哈希，同UUID不能换内容。取消屏障和提交共用事务锁；旧成功回执只读取最新说明，不再次执行旧保存。
- `task_notes`仅允许有权限成员直接读取；写入只能通过RPC。`task_note_receipts`无客户端表权限，不另存正文。审计只记版本和字符数。

客户端校验返回范围、版本、格式及回执账号；串行保存本机草稿，拒绝过期账号、仓库生命周期、孩子删除、家庭撤销和注销后的响应。明确的权限拒绝清除本机说明；普通网络失败保留可恢复内容。家庭离线设备无法立即得知远端撤销，仍沿用已有前台联网权限核对机制。

## 导出、清理与验证

孩子数据导出增加第40类`task_notes`，包含当前正文、版本、更新时间和编辑者账号ID；不导出私有请求回执。本机草稿不属于云端导出范围。任务/孩子删除级联清理说明和回执；账号删除清除该账号回执，其他家庭保留的共享说明通过外键将编辑者置空。

`test/task_notes_test.dart`的16项检查覆盖真实文件库关闭/重开、草稿与原请求恢复、原请求重放及最新说明、只读核对和取消、账号/孩子/成员/注销/仓库失效、迟到保存、权限拒绝、Unicode长度、SDK参数、已完成任务入口、离线输入和双倍字号交互。

`scripts/test_task_note_cases.mjs`的5组检查覆盖无PIN共享、任务/钱包不变、旧回执不覆盖新说明、取消屏障、长度和权限、两个真实PostgreSQL连接竞争、40类导出以及删除级联。已有导出测试同时验证所有服务端类别可被Flutter ZIP生成器接收。最终全量574项Flutter、310组数据库通过，核心覆盖率89.37%。
