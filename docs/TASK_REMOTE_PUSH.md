# iPhone 任务提醒：收到后复查安静时段

2026-11-06，用户确认优先安静，接受远程提醒受断网、强退和系统限制而缺失。iPhone 任务提醒改为 APNs data-only 消息，原生接收后校验再提交即时本地通知；不再使用后台不可拦截的本地定时通知。Android 继续使用已有的 TaskAlarms。应用内任务和提醒列表保留。

这项选择不能保证操作系统最终展示的时刻。Apple 后台投递可能限流或不执行；应用只能在收到消息和前台展示回调中检查。服务端接受、APNs 接受、手机展示和用户阅读分别是不同状态。真实 APNs、签名 iPhone 和鸿蒙4.2仍需验收。

## 服务端

- 迁移067将候选生成抽为私有函数，保留开始前10分钟、开始时、截止前15分钟、相同时点合并、计划请假和已读过滤；内部发送路径另外包含15分钟内已到期的复习稍后提醒，公开未来候选接口的行为保留。
- 设备注册独立于家长消息，绑定账号/家庭/当前孩子。设备随机能力密钥仅在安全存储中保存，服务器保存摘要。prepare/activate/renew/revoke使用递增意图版本；退出后的迟到激活、旧撤销及其他账号不能取得新范围。匿名撤销仅凭该设备能力，不携带旧登录凭据。
- 迁移068提供私有队列：每设备版本/合并时点唯一；每轮入队最多200条、领取最多20条、发送并发4、最多5次尝试。租约可恢复，旧工作者结果无效，最近15分钟以外的提醒不补发。
- 发送前再次检查有效成员、孩子删除标记、任务终态、已读、设备范围/有效期、令牌摘要、家长开关和当前安静时段。孩子/成员/账号删除会清理设备及关联队列；保留清理移除过期注册和旧队列。
- payload只有11个固定字符串字段：版本、消息ID、随机范围nonce、固定类型、原提醒时点、签发/到期、时区、安静起止、策略版本。没有任务标题、孩子姓名、题目、答案、账号/孩子ID或任意通知正文。消息期限最多60秒。
- APNs使用background类型、priority 5、expiration 0及按范围合并；无alert字段。接受回执不会完成任务、发奖励或标记提醒已读。APNs拒绝令牌时仅停用该次令牌版本。

## 客户端

`RemoteTaskPush`在系统授权、本机选择及当前孩子范围有效时注册；安全存储记录与家长推送分开。切换孩子、切换到家长消息、退出和隐私清理会先关闭原生接收，再保存撤销意图及异步重试网络撤销。迟到RPC和MethodChannel响应不能越过本机修订号。

原生接收不打开Flutter数据库，只保存范围、服务器时钟锚点、策略版本、消息去重及最多60个不含任务正文的有效提醒时点。列表来自现有候选和本机离线任务状态过滤；本机已完成/取消的提醒被移出后，即使服务器仍认为任务待完成，收到消息也不显示。当前孩子范围和提醒列表还没恢复时不会显示。

接收时检查精确字段、范围、短期限、原提醒15分钟期限、有效列表和服务端/本机两份安静策略。服务器时间由包含休眠的连续时钟推进；往返校准最多10秒，整个不确定区间逐秒检查，避免越过短安静区间。重启、时间跳变超过30秒、授权到期或旧设置版本都会停止接收，需要再次打开应用同步。每次回到前台会立即更新设备令牌与时钟，不等待12小时的常规续期；该控制器只在iOS创建，Android不增加此项安全存储初始化。前台显示即时通知时还会再检查一次。

最多60条、七天候选窗口也意味着长期不打开应用、新增任务未同步、收到前名单已更新或设备重启时可能漏提醒。消息只显示固定文案；打开应用后按正常账号/家长PIN权限查看详情。旧iOS本地定时通知在范围初始化时清理，无远程配置时明确提示，不回退到本地定时。

## 配置与部署准备

本次没有部署云端或调用Apple服务；默认调试构建不启用远程任务提醒。准备好用户的Supabase和Apple项目后：

1. 应用全部迁移至068，部署`task-push` Edge函数。
2. 只在Edge服务环境配置`TASK_PUSH_APNS_KEY`、`TASK_PUSH_APNS_KEY_ID`、`TASK_PUSH_APNS_TEAM_ID`、`TASK_PUSH_APNS_TOPIC`、`TASK_PUSH_APNS_ENVIRONMENT`。topic须与签名Bundle ID一致（当前工程`com.learningplanet.learningPlanet`），环境与签名描述文件一致。私钥不得进入Dart define或仓库。
3. 审核后运行`supabase/operations/enable_task_push.sql`，复用已配置的Vault项目URL和服务凭据，按分钟调用服务端接口。它不是迁移或本机测试自动执行的一部分。
4. iPhone构建设置`--dart-define=TASK_REMOTE_PUSH=true`，完成签名及Push Notifications/后台远程通知能力，用户在应用中授权通知。
