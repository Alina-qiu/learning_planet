# 家长纠正任务计时

2026-11-05。补齐TSK-05中的计时纠正；原有补签继续保留。是否包含撤回误完成仍待用户答复，本轮不据此认定整个TSK-05已完成。

## 使用方式

家长验证当前家庭PIN后，在任务管理的任务卡上选择“家长纠正计时”。页面联网读取服务器当前累计时长，填写实际累计分钟、剩余秒数和必填原因，再确认纠正。原因最多500个Unicode码点；总秒数沿用任务字段的0–2147483647整数范围，分钟与秒数分别校验。

已完成、暂停、放弃等停止计时的任务都可纠正，包括自动错题复习的累计时间。进行中的任务必须先暂停并同步。本机存在该任务的未同步操作或冲突时拒绝读取/保存，提示先处理同步；其他设备随后修改任务时，保存会因版本变化被拒绝，需要重新读取。

纠正只更新累计时长，保留完成状态、完成日期、首次开始来源、复习答案、计划进度及已有金币/XP。暂停任务之后正常完成时，最低有效时长按纠正后的累计值校验；家长本身拥有原有补签权限。学习报告和孩子导出读取纠正后的当前时长，审计保留操作者、原因、前后秒数、版本和状态。

## 版本、重试与权限

迁移057提供 `task_time_context` 和 `correct_task_time`。读取与提交均需当前登录会话的家长PIN；提交锁定任务后复查真实授权到期时间。家庭、账号和任务删除/撤销与修改通过现有锁和可见性检查隔离。

请求携带固定UUID、读取到的同步版本、目标累计秒数及原因。服务器只在版本一致且时长发生变化时更新，既有触发器推进同步版本；这会使其他设备的旧离线任务命令进入冲突流程。两台设备同时纠正同一版本只接受一个请求。私有回执绑定账号/UUID/任务/参数哈希，同一请求重放只返回原受理版本与最新任务，不再次更新或重复审计。

客户端捕获账号、家长授权版本及本机隐私版本，读取和写入前后校验。账号/PIN/成员变化、孩子删除、注销、仓库销毁或离线队列改变后的迟到响应不能恢复界面。页面在PIN失效时隐藏时长和输入内容，实际权限仍由服务器判断。

网络中断或回复不确定时，当前页面冻结输入并允许重试原请求。此请求只保留在页面内存，关闭或重启后需重新打开并读取服务器核对；不会自动重放家长操作。服务器版本校验防止关闭前的迟到请求覆盖后来版本。返回任务页会同步并刷新任务及报告；如果再次断网，任务列表可能暂时显示带离线提示的原缓存，应恢复联网后核对。纠正不新增离线写入或金融结算。

回执不出现在普通查询或孩子导出中，任务/账号删除时级联清理；纠正后的任务字段及审计进入既有40类导出，无新增导出类别。
