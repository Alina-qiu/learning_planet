# 账号注销与家庭解散

2026-11-05补充[真实注销服务集成](PRIVACY_INTEGRATION.md)：文件清理依赖/失败、实际Auth硬删除但回执丢失、重试完成、旧凭据拒绝和共享家庭资料保留通过；共享清理worker已修复Storage HEAD400兼容问题。测试推进合成任务时钟，不能视为线上Cron或24小时期限验收。

迁移023及客户端实现 PRD AC-10 的账号注销流程。当前为代码和本地验证交付，未部署到真实 Supabase，尚无24小时线上清理时限的验收证据。

## 使用范围

家庭管理右上角或尚未创建家庭的页面 → 注销我的账号 → 验证每个家庭的家长 PIN → 预览范围 → 输入“永久注销我的账号”。没有家庭的新账号也能注销。只能注销当前登录账号，接口不接收目标用户ID。

| 范围 | 处理 |
|---|---|
| 本人创建的家庭 | 解散家庭；按迁移022同事务删除所有孩子业务数据并保留可信文件清单，冻结家庭访问。其他成员的登录账号不删除 |
| 本人加入的其他家庭 | 保留家庭、孩子、已编辑错题、学习结果、钱包和账本；退出成员关系，删除本人OCR来源和PDF，移除关联导出快照，审计正文清空并解除账号关联 |
| 云端图片/PDF | 包含孩子清单、本人上传对象、本人OCR/PDF来源和所拥有家庭目录遗留对象。调用Storage API删除并验证后才进入Auth删除，不在SQL中删除Storage索引 |
| Auth登录账号 | 所有相关文件工作结束、家庭记录已清理后，由服务端Admin API硬删除。失败保留任务，指数退避重试；API缺少用户的结果还须由数据库独立验证 |
| 本机 | Drift schema3清除该账号全部缓存和待同步操作，持久标记阻止迟到快照或新命令写回；清空内存图片及提醒。本人家庭被删孩子也清除其他本机账号的对应缓存 |
| 其他设备 | 登录时、恢复前台和运行期间每30秒查询注销状态。收到注销结果即清除缓存并关闭旧详情；其他家庭成员通过UUID通知清理已解散家庭孩子的缓存 |
| 外部副本 | 用户自行管理已经导出、下载或分享的文件，不能远程擦除 |

保留其他家庭的学习记录意味着其中由用户输入的任意文字不会自动识别为个人信息并全部抹除；界面明确区分家庭学习内容与本人上传来源。此流程不提供家庭所有权转移；希望保留本人创建的家庭时，应停止注销并先导出所需资料。

## 时限、状态和保留

- 受理后立即禁止原账号读写学习数据，本人创建的家庭也停止成员访问。受理不等于文件或登录账号已删除。
- 文件至少等待10分钟；等待旧PDF租约截止再加10分钟，并等待已有孩子/本人清理任务完成。部署不同生命周期的worker前需重新核对这个窗口。
- 界面显示24小时预计完成时间，超过时限仍展示未完成并提示联系支持。服务失败不会被伪装成成功；自动重试最高间隔6小时。**上线前必须为超时和失败建立监控和值守，才能验收清理承诺。**
- 完成任务保留30天，仅保留请求UUID、账号UUID、状态和时间；完成时擦除清单及家庭/孩子数组。可信drain清除过期记录。Auth已不存在的账号即使记录过期也不能用旧JWT重建家庭。
- 其他成员的家庭撤销通知只包含成员/家庭/孩子UUID及时间，保留至该成员账号删除，保证长期离线后能清理缓存。
- 删除的共享图片/PDF路径仅含UUID和固定文件名，保留不可重用标记至所属家庭删除；无有效家庭归属的遗留路径标记持续保留。不保留图片、OCR正文或原账号身份。
- 以上期限针对主数据库和应用管理的文件。云备份实际保留期、操作系统临时文件、已离线设备即时擦除仍需部署政策和真机验收。

## 安全和重试协议

`account_deletion_context`列出本人家庭及会话PIN有效期；`preview_account_deletion`要求所有成员家庭的当前会话PIN，返回家庭/孩子/文件数量与范围版本。`request_account_deletion`只使用auth.uid()，精确短语、范围比较、账号行锁、请求UUID和事务保证未知响应重试不重复删除。范围变化返回40001，需要重新预览。

账号任务无Auth外键，避免删除Auth时丢失尚未完成的清单。`is_family_member`和`is_family_admin`检查账号及家庭冻结状态，已移除旧families_select策略中的创建者绕过条件。新增账号所属记录会与注销事务串行，已冻结家庭不能被旧请求新增孩子。这里不能只依赖退出登录：[Supabase说明JWT可能在到期前仍有效](https://supabase.com/docs/guides/auth/managing-user-data)。

只有service_role能领取、准备和完成注销。Edge对普通调用者通过getUser验证身份，再查询其本人的注销状态，忽略客户端提供的用户ID、任务ID和路径；drain只接受服务端凭证。共享家庭中删除的文件UUID不能被旧请求重新创建。所有文件API和AuthAPI结果都通过SQL完成门禁再验证。[Auth Admin删除仅用于服务端](https://supabase.com/docs/reference/javascript/auth-admin-deleteuser)，[Storage删除必须使用文件API](https://supabase.com/docs/guides/storage/schema/design)。
