# 按孩子导出数据

对应 PRD ACC-05 的 CSV/图片索引及按孩子导出要求。迁移021、Flutter入口和本地回归已实现，迁移032补充AI分析类别，迁移034补充AI练习题来源、采纳回执及反馈；未部署真实Supabase，未完成Android/iOS系统保存器及文件清理的真机验收。孩子/账号整体删除的本地实现见对应文档，线上验收仍待完成。

## 使用流程

家庭管理 → 孩子右侧“导出孩子数据” → 查看各类记录数量 → 输入“导出孩子数据” → 生成快照并分页读取 → 保存ZIP。需要家庭管理员身份及当前登录会话的有效家长PIN。普通家长会收到权限提示，孩子模式不读取导出数据。

预览后记录数量改变会要求刷新范围并重新确认。只导出已同步云端记录；用户应先完成离线同步。下载时显示记录进度，支持取消。页面关闭、账号变化、PIN失效或快照被清理撤销时，中止读取；所有分页收齐、压缩完成后，再向服务端校验一次快照，才交给系统保存器。

## 内容与格式

ZIP包含40个CSV、原始值`data.json`、清单`manifest.json`及`README.txt`。空类别仍有表头，清单含字段、行数、快照时间及文件SHA-256。文件名仅使用孩子及请求UUID。`ai_analysis`包含可读取的分析回执与建议，排除输入摘要及claim token；正文过期、清除或删除时撤销相关临时导出副本。迁移034新增`ai_question_origins`、`ai_question_adoptions`和`ai_feedback`，记录已审核题来源、去重保存回执及反馈的模型/提示版本，回执不含owner_id与config_hash。

迁移054新增`task_notes`，导出当前共享说明、版本、更新时间和编辑者账号ID，不含本机草稿及私有保存回执。当前40类均已通过服务端快照与客户端ZIP类别兼容检查；需要使用包含本次类别更新的客户端。任务/孩子删除级联删除说明；账号清理后其他家庭保留的说明将编辑者置空。

迁移043新增 `family_retention` 和 `family_activity_days` 两类家庭共享回访数据，不标识具体孩子或操作者；起点、日期、补传与删除口径见[家庭回访说明](FAMILY_RETENTION.md)。迁移044新增 `parent_configuration_time`，仅导出当前家长为该孩子产生的90天内配置区间，排除其他家长及owner_id/载荷哈希，详见[配置用时](PARENT_CONFIGURATION_TIME.md)。迁移048新增 `review_reminders`，包含复习队列预约时间、延迟分钟数、修订号和请求时间，排除内部命令UUID，见[复习稍后提醒](REVIEW_REMINDERS.md)。迁移048阶段的39类导出清单已被客户端支持；客户端需升级到支持这些类别的版本才能打包。

迁移035在`wrong_questions`中增加`error_reason_tags`列，保存人工确认的六类标签编码；原`error_reason`备注保留，不从历史备注推断标签。迁移036新增`ai_report_feedback`，记录周报条目编号、不准确反馈及模型/提示版本；已完成且未过期的周报正文与权威依据放在`ai_analysis.result`，运行中的依据不导出。

迁移038新增`parent_notification_receipts`，只导出当前家长自己的孩子消息已读/送达回执，不包含其他家长的回执或账号/家庭标识。通知偏好属于家长而不是孩子，不纳入孩子导出。送达仅表示已提交系统通知，不代表已读。

| 类别 | 内容 |
|---|---|
| 孩子及任务 | 档案、模板、实例、长期计划、请假、阶段奖励及终奖规则 |
| 金币与奖励 | 钱包、金币规则、账本、待确认金币、家庭共享奖励目录、此孩子的兑换与表扬/考试 |
| 错题与复习 | 含归档题的错题/拼音、标准答案、历史复习、私有答案快照及复习队列预约 |
| OCR与文件索引 | 已保存题目的OCR来源、当前管理员本人的未保存草稿、图片路径/存在标记、未过期组卷及题目快照 |
| 成长及设置 | 成长日期、连续里程碑、解锁资产、角色设置、提醒设置/已读记录、同家庭内关联孩子的操作审计 |

不包含兄弟姐妹记录、其他家长未保存草稿、Auth表、PIN、工作租约、访问令牌、签名链接或图片/PDF二进制。家庭共享奖励目录是明确列出的家庭级数据。永久删除记录按现有清理规则脱敏；清理中的孩子不能准备新导出。图片存在标记是快照时的Storage索引状态，不证明外部对象存储实时可用。

CSV采用UTF-8 BOM、CRLF和双引号转义；数组/对象为JSON字符串。可能被表格软件当作公式的文本前加单引号，数字保持原值；`data.json`保留未经该处理的原始值。目前不支持导入恢复。

## 权限、完整性和临时内容

- 所有导出RPC再次验证管理员、家长PIN和JWT session_id。临时表启用RLS并撤销直接访问权限，私有数据源函数不可由客户端或普通service_role直接执行。
- 服务端以同一SQL快照冻结全部类别，后续改题/新增任务不改变已确认的导出。请求UUID绑定孩子、用户、会话；相同请求可幂等读取，新的确认会撤销该用户同一孩子的旧快照。
- 每页最多250行、目标JSON负载1MiB；单条超大OCR记录允许独占一页，避免截断或游标停滞。客户端验证类别、总数、游标、结束标记和实际收齐数量，字段不符或归档路径非法则拒绝生成ZIP。
- 快照最多可读15分钟。正常保存/取消/失败结束时关闭并删除临时内容；关闭不再要求有效PIN，但仍绑定原用户和会话。网络失败留下的内容需由Cron删除；超时后即使Cron停机也不能通过导出RPC继续读取。保留的任务元数据不含题目和答案正文。
- 任一该孩子的永久清理任务入队时，同事务撤销其导出并物理删除临时正文，防止通过旧快照重新读取已清理内容。准备导出与清理使用同一孩子锁串行化。
- Dart不把ZIP写入业务缓存。锁定的file_picker 13.1.0在iOS使用NSTemporaryDirectory中转，原生通道只删除严格匹配`learning-planet-<child UUID>-<request UUID>.zip`的普通文件，不递归、不接受客户端路径、不触及其他临时导入；在保存前、保存结束以及应用启动时清理。通道失败会阻止新保存或显示清理失败，避免错误报告成功。
- 系统保存器接管之后，用户选择的本地/云盘副本不受服务端远程撤销控制；应用关闭时的iOS中转文件会在下次启动重试清理。原生文件行为仍需真机验证，Dart通道mock测试不能替代它。

iOS通道沿用当前工程的隐式引擎生命周期，在`didInitializeImplicitFlutterEngine`注册；注册方式依据[Flutter平台通道文档](https://docs.flutter.dev/platform-integration/platform-channels)。

## 部署与验收

1. 审查目标项目并按顺序应用未部署迁移至048（基础导出始于021），不在真实项目运行db reset。
2. 若已有pg_cron，迁移会注册每分钟的`learning-planet-export-maintenance`。否则启用扩展后执行`supabase/operations/enable_task_maintenance.sql`；已有其他维护任务仍保留。
3. 在目标环境确认Cron实际运行、15分钟到期的`child_export_rows`已被删除、维护失败有运维可见记录。只有可信维护角色能调用`run_child_export_maintenance()`。
4. 使用真实两个家庭、普通家长和管理员验证预览/分页/账号切换/授权过期；确认ZIP不含其他孩子或未保存的他人草稿。
5. Android/iOS保存ZIP并核对CSV中文、多行、表格公式处理、JSON值和哈希；覆盖取消、断网、终止应用、iOS重启清理及与永久清理并发。大数据量的客户端内存、服务端快照耗时需在staging测量。

本地专项覆盖中文及CSV转义、文件哈希、分页缺失拒绝、孩子门禁、二次确认、授权失效、取消、最后一次服务端校验、iOS通道清理及并发保存限制；数据库覆盖29类结构、跨家庭审计隔离、280行稳定分页、超过1MiB单条OCR、UUID重放、权限撤销、永久清理撤销及过期正文删除。隔离数据库使用模拟Auth/Storage，不代表云端联调完成。
