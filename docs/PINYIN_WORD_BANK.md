# 拼音词库、导入与练习卷

2026-11-04核对PRD 6.6。自定义词语、生词库导入、错词转入和三种纸面出题模式已接入本地实现；云端与原生设备验收未完成。

## 家长操作

在“错题与拼音复习”进入家长模式并验证PIN：

- “拼音词库 → 新增拼音词语”：输入词语、语境、1至5个可接受读音。可填入本地候选，再按教材确认。
- “拼音词库 → 导入生词库”：选择UTF-8 CSV/TSV/TXT文件或粘贴带表头的内容，每批1至100条、最多256 KiB。解析后逐条修改、确认；不会自动勾选全部确认。
- 语文错题卡片的“转为拼音词条”：提取词语、填写读音后保存。沿用原记录ID及内容版本，原图片和旧复习快照保留；当前条目移到词库，未来复习进度重置。不是另外复制一份无法追踪的错题。
- 导入成功后可以把新增词语直接带入“A4组卷与PDF”，也可以稍后按条件选题。

模板如下，知识点列可省略。拼音留空时，必须在预览中补齐；语境也必须补齐后才能确认保存。带逗号、换行的字段使用双引号，字段内部双引号写成两个双引号。

```csv
词语,拼音,语境,知识点
银行,yín háng,我去银行存钱,多音字
妈妈,mā ma,妈妈回家了,轻声
```

文件在本机解码解析，只向服务端发送核对后的词条，不上传原CSV文件。输入内容不会被当成公式或代码执行；不接受XLSX或自动猜测GBK编码。

## 候选读音与确认

固定依赖 `pinyin_pro_flutter 1.0.3`，随客户端包含本地词典，输入词语与语境不发送到外部拼音网站。语境包含词语时按整句生成候选，再提取对应词语；显示该词中多音字的备选读音。

默认不把“一、不”自动改为变调标注；家长可打开“候选考虑‘一、不’的变调”后重新生成。轻声以无调符号表示；单元测试覆盖妈妈、银行、不是、一天。候选不是权威答案，词库覆盖和语境识别有局限，其他变调、特殊读法和教材要求由家长手工审核。修改词语、语境或读音会撤销原来的确认状态。生成候选、录入和导入均不发奖，也不改变任务完成状态。

依赖功能与许可来源：[发布包及API说明](https://pub.dev/packages/pinyin_pro_flutter)（MIT）。本项目只调用本地转换接口，不使用其HTML输出。

## 复习与三种出题模式

| 需求 | 实现及证据 |
|---|---|
| 看词语写拼音 | 词库进入既有每日自动复习及服务端声调判定；PDF也支持该方向 |
| 看拼音写词语 | PDF展示确认读音，并遮蔽例句中的目标词语；答案页展示词语 |
| 随机混合 | PDF在固定快照内确定方向，相同请求重试输出一致；多词样本包含两个方向 |
| 四线三格、田字格 | 可分别选择、同时选择或不使用格线 |
| 题量、留白、答案页、重复次数 | 按选题决定1至100题，0至12行留白，答案/解析独立开关，1至5次重复 |

在线每日复习目前仍是“看词语写拼音”；三种模式用于组卷。新增词条进入后续自动复习，已冻结的当天题集不追加新词。已归档、已掌握等状态仍遵循既有调度规则。

PDF渲染器升级到 `a4-v2`：能在一页放下的短题及全部书写格一起分页；超过一页的长题和作答区保留续页。已经生成的PDF不重新渲染；新生成结果记录新的renderer_version。

## 迁移028与数据边界

`import_pinyin_words`要求当前家庭有效会话PIN，校验每一条的类型、长度、语境、确认状态和标准读音，再调用原有错题保存事务。一条不合法时整批回滚。

同一孩子下，相同词语与语境（去首尾空格）已存在时跳过，保留原读音、内容版本、掌握、归档及复习记录；同批重复也被跳过。不同语境允许独立词条。结果显示新增数量、跳过数量和对应记录行号，不静默覆盖旧词条。

`pinyin_import_receipts`只保存请求UUID、孩子ID、内容哈希、结果ID及时间，不保存第二份词语或答案。客户端无直接表读写权限，回执随孩子删除级联清除；作为内部操作回执不加入学习内容导出。实际词条及标准答案沿用既有导出和删除路径。

同UUID同内容返回原回执；改内容或换孩子复用UUID会拒绝。复用回执不会重建已被删除的词条。两个设备用不同UUID同时导入相同词条，也只创建一份。导入不改变钱包、账本或已有任务快照。

客户端遇到未知网络结果会冻结原内容，当前页面重试保留原UUID；数据库明确拒绝后可以修改草稿。离开页面不持久保存请求草稿，应先查看词库再重新导入。读音确认和导入写入需要联网，不作为离线作答队列的一部分。
