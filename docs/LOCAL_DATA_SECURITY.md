# 本机数据加密与恢复

2026-11-04：落实PRD“传输与存储加密；密钥不进入客户端包”的本机数据库和登录凭据部分。服务端RLS、私有Storage、家长PIN与按账号/孩子隔离继续独立生效，加密不代替授权检查。

## 已实现

- Drift升级至2.35.3，sqlite3升级至3.8.0；通过pubspec的原生构建hook打包SQLite3MultipleCiphers。生产启动必须检测到加密引擎，正式构建同样检查，不回退到明文SQLite。
- 明确选择ChaCha20方案。首次启动使用`Random.secure()`生成256位随机密钥，由flutter_secure_storage存入设备安全存储。密钥不来自PIN，不写入源码、数据库、普通偏好设置或日志。写入后回读确认，才创建加密文件。
- Android关闭插件的`resetOnError`，避免密钥异常时自动删除安全存储；启用插件迁移保护。iOS使用`unlocked_this_device`、关闭钥匙串同步，并配置Runner的Keychain entitlement。
- 整库包含缓存、普通/复习命令、答案、图片BLOB、OCR/校对草稿与删除标记。使用内存临时表及`secure_delete=ON`。数据库和WAL的实际文件检查均未发现测试载荷明文。
- Supabase会话及PKCE校验信息改用安全存储。旧偏好设置迁移先写入、回读确认，再移除原值；其他设置保留。串行写入、退出登录标记与当前会话检查阻止旧响应恢复已退出账号。主动退出先等待安全存储清理完成，失败时向调用者报告。
- 启动过程中先完成数据库和凭据准备，再初始化网络会话/同步。发生错误显示中文提示与重试按钮，保留文件；不会展示底层异常中的密钥、凭据或路径，也不自动清空本机数据。

## 2026-11-05 断网退出与会话隔离

首页、空家庭、首次建家、家庭加载/错误页和账号状态页共用退出流程。先关闭本机家长权限及提醒，再暂停会话持久化、尽力撤销服务端PIN授权（最多等待3秒），确认安全存储中的PKCE与会话退出标记已写入，最后退出SDK本机会话。界面在清理期间阻止继续操作；本机存储或原生清理失败时提供固定重试提示，不显示底层凭据和错误细节。

服务端离线或注销HTTP请求未返回，不妨碍已完成本机清理的账号回到登录页。SDK临时监听器取消后的异步收尾不阻塞退出界面；SDK在删除内存会话后未发出事件的异常路径也会触发页面关闭。重复退出共用一次请求；会话发生变化时中止旧退出意图，恢复新账号的持久化，迟到的网络失败不能清除新登录。

退出标记和会话写入共用串行队列，版本检查阻止排队中的旧认证事件覆盖退出标记。账号变化时关闭旧详情页、失效业务Provider并清理内存图片缓存。普通退出保留按账号隔离的加密离线命令，原账号再次登录可继续同步；不将普通退出当作删除资料。

单独退出家长模式也先关闭本机权限。账号变化、主动退出或退出家长模式都会推进授权版本；先前尚未返回的PIN验证不得恢复家长模式。

本机退出不证明服务器已撤销全部凭据：离线期间已签发JWT仍受其有效期约束，现有服务端PIN授权最长10分钟。客户端不为注销重试保存旧JWT；家长推送仅保存独立的匿名撤销能力，前台恢复后补传，见[远程通知](PARENT_REMOTE_PUSH.md)。网络等待超时不保证底层请求取消。本轮未改变SQL，也未在真实Auth/KeyStore/Keychain或手机上验收。

`test/sign_out_test.dart`的19项检查覆盖断网、悬挂请求、重复退出、迟到失败、新账号登录、存储故障/重试、PKCE异常、排队持久化、六类退出入口、真实SDK与完整应用的本地模拟、权限关闭和迟到PIN。全量结果见[测试记录](TESTING.md)。

## 2026-11-05 修改家长PIN与迟到回执

家庭设置中的修改PIN入口补齐与登录/退出相同的本机授权隔离：打开弹窗前保存账号、仓库、家庭及授权版本；提交前、保存返回后和验证返回后都复核。账号变化、退出家长模式、授权到期、切换家庭或页面销毁后，旧请求不能发起后续验证或覆盖新的本机权限。已经发出的服务端修改不会因关闭页面而自动撤回；此检查不冒充网络取消或跨设备即时撤销。

PIN格式和两次输入在本机校验；同一设置页有操作进行时禁用重复提交。只有服务端验证成功并返回未来的有效期才显示“家长PIN已更新”。保存成功但验证失败、有效期缺失/过期会关闭当前本机授权并要求重新验证；明确的SQL权限/输入拒绝与网络、HTTP网关导致结果未知分别提示，不自动重发修改，不回显原始异常或PIN。已核对所用Postgrest SDK会将HTTP503等错误包装成PostgrestException，因此不能只凭异常类型宣称保存被拒绝；SDK的POST请求也不会自动重试。

沿用服务端迁移005：修改仍仅限管理员和有效授权，已有PIN更改会撤销该家庭的服务端授权，再为当前合法会话建立授权。五次失败锁定十分钟、其他设备离线缓存及JWT有效期没有被客户端修改。

手机截图发现家庭设置将操作按钮放在ListTile尾部，导致普通字号时“添加孩子”被下方卡片覆盖、大字号时家庭名称竖排。现改为家庭信息下方独立换行操作区；PIN弹窗支持滚动并以短标签和单独格式提示适应系统字号。360px的1倍/2倍中文截图已复核，测试包含按钮可点击及不与孩子卡片重叠检查。

回归文件为`test/parent_pin_settings_test.dart`；旧实现复现“撤销后迟到验证将parentMode改回true”，记录保留在`tmp/parent-pin-regression-before.log`。全量数字见[测试记录](TESTING.md)。未改SQL、Kotlin或Swift，真实后端与两端手机仍需验收。

## 旧数据迁移

旧文件为应用支持目录中的`learning_planet.sqlite`，新文件为同目录的`learning_planet.encrypted.sqlite`。加密迁移最初对应Drift逻辑schema4；当前schema5另增加家庭权限状态表，保留原缓存、队列和图片，见下方成员权限说明。

1. 读取/创建并确认设备密钥。若新文件或迁移文件已经存在而密钥缺失，直接停止，禁止生成替代密钥。
2. 在后台isolate读取旧库，通过SQLite `VACUUM INTO`复制已提交内容（包括旧WAL中的记录）。旧库在迁移完成前保持权威。
3. 将临时副本加密、关闭重开，使用密钥执行完整性校验；通过后同目录重命名为新文件，并再次验证。
4. 仅在加密副本验证成功后清理旧文件和迁移文件及其sidecar。清理失败时阻止进入应用并可重试。

重启时，已验证的新文件优先，旧副本不能覆盖加密库中的后续工作。新文件不存在而旧库存在时，重新制作迁移副本；若只剩迁移副本，则只有它可以用原密钥解锁且校验通过时才接续恢复。未知格式、错误密钥、损坏文件均保留资料并报错。

迁移期间临时副本先为明文，然后执行rekey；它仅位于应用私有目录。迁移中断可能留下该副本，下一次成功启动会处理。旧文件的unlink及SQLite逻辑清理不能证明闪存历史块、既有系统备份或第三方缓存已物理擦除。

## 备份和真机边界

Android配置`allowBackup=false`，并同时提供旧版备份排除和Android 12+云备份/设备迁移排除规则，覆盖私有文件、数据库和偏好设置。iOS通过原生通道为应用支持目录设置备份排除及完整文件保护，并处理已有数据库文件；创建加密库后再次确认文件保护设置。

未同步答案和图片仍只在原设备上；卸载、清除应用数据或永久丢失密钥可能使它们无法恢复。已同步业务资料仍由服务端保存。当前没有重置密钥或擦除本机数据库按钮，不能把错误提示中的“重试”理解为可恢复永久丢失的密钥。

尚未完成以下真机验收：

- Android/iOS发布构建确实包含加密引擎、KeyStore/Keychain读写和签名entitlement有效；前后台、锁屏、重启解锁后的行为。
- 含离线答案和图片的旧版本原地升级，在复制、加密、重命名、清理阶段杀进程，验证UUID、顺序、重试次数和删除标记。
- 空间不足、设备安全存储暂不可用、密钥丢失、文件损坏时不丢原数据；重试后不会重复同步或发奖。
- 系统备份、厂商换机迁移、iOS备份及重装后的行为；既有备份不会被本次配置追溯删除。
- 相机/相册、OCR、打印、导出和通知插件自身缓存与系统通知内容。这些位于数据库之外，本次整库加密不等于已完成所有原生缓存保护或物理删除验收。

## 2026-11-05 家庭成员权限撤销

schema5新增按账号/家庭的版本化权限状态和通知清理待办。迁移050提供只返回当前账号状态的接口，无需PIN即可完成撤销清理；被移除或家庭解散的通知保留到账号删除。应用前台进入、恢复及每15秒联网核对；任务同步前也先核对。获知撤销后事务清理对应账号在该家庭的缓存、离线队列及图片，保留其他账号/家庭；不将共享孩子标记为已删除。

最后撤销版本确保设备错过移除、重新加入后才联网时仍清理旧资料；图片UUID屏障和权限版本检查阻止迟到回调复活旧草稿/快照。原生提醒清理失败时待办保留，下一次网络请求前先重试，旧版本确认不能消除新待办。页面关闭和本机PIN清除限定受影响的家庭。离线设备和已投递系统通知无法远程即时抹除；后端和两类手机验收待完成。接口、检查与限制见[家庭成员](FAMILY_MEMBERS.md)。
