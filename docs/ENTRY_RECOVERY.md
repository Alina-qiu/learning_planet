# 登录与家庭加载恢复

更新：2026-11-06。对应PRD 6.1的邮箱登录、家庭数据读取与账号管理，以及首次使用流程。本机服务重启后，App仍持有旧测试会话，原界面直接显示`PostgrestException`和数据库错误；登录状态监听失败的界面还缺少恢复操作。本轮从实际联调问题补齐恢复入口。

## 当前行为

登录状态、家庭资料、账号注销状态三个入口共用可滚动的恢复页面。网络/超时错误提示检查网络，确定的失效会话提示重新登录，其他错误按当前读取步骤给出中文说明。普通权限拒绝不直接断言账号被删除或令牌失效；数据库、认证和原生错误正文不出现在这些入口中。

“重试”只重新读取当前失败步骤。请求进行中或安全退出进行中不可重复点击重试；持续失败可继续重试或退出。网络错误不会自动登出，也不把读取失败当成空家庭或已完成注销检查。账号状态检查成功后，才继续原家庭入口。

“退出登录”继续调用现有共用流程：先关闭本机家长授权、清理提醒，再退出账号。清理失败时显示退出未完成并允许重试。账号范围内的待同步记录和既有离线回退规则未改，未增加清空数据或重建家庭操作。正常和双倍字号均保留系统安全边距。

核心覆盖率6518/7167（90.94%，107文件），完整分析42.5秒无问题，268个Dart文件格式通过。一次测试文件的花括号lint修正后重新分析通过。日志为 `tmp/entry-recovery-related-tests.log`、`tmp/entry-recovery-full-tests.log`、`tmp/entry-recovery-coverage.log`、`tmp/entry-recovery-analyze-final.log` 和 `tmp/entry-recovery-format-final.log`。

原始问题先在测试中复现：旧界面将带合成私有标记的数据库message/details/hint直接呈现。随后实际API36旧APK再次复现`账号不可用`底层异常，旧会话来自上一轮临时服务；当前临时服务保持独立、真实的Auth/PostgREST。日志：`tmp/entry-recovery-before.log`、`tmp/entry-recovery-before-ui.json`。测试首次全跑的失败来自测试容器在计时器检查后才销毁，已改用随页面释放的ProviderScope；没有修改生产计时器或放宽恢复断言。

本轮未修改数据库、原生代码或SDK版本；此前387组SQL、5项真实奖励HTTP及34项JVM记录仍按其原验证范围使用。启动跟踪仍指向模拟器绘图表面创建期间的等待，本轮不将恢复界面的改动计作性能优化；云端、华为鸿蒙4.2、iPhone和完整启动性能继续待验收。最新产物及实际界面结果见[构建记录](ANDROID_BUILD.md)。
